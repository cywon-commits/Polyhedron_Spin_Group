# H6: C–F 경계의 저온 기울기 — 판 공존 + Clausius–Clapeyron 결합 맞춤 결과

설계(승인, Oct 15): T = 0.10, 0.125, 0.15, 0.175, 0.20, 2D L = 24 판(대각선 계면), K = 0.5, zH₄ = 1.5, zG 1.000–1.100(0.005 간격 21개) × 시드 3개, 12000스윕; Clausius–Clapeyron 사슬(L = 24, zG = 1.02, 1.05, 1.08, 분기마다 단일 온도 사슬 5개 온도). 예측: zG\*(T) = J + aT + bT²에서 a = 0.382(조화 + 라벨), 0.224(라벨만), 0.158(조화만). 구현 세부와 두 번의 수정(보폭 조정을 복사본에서, 초기 과도 구간 속도, 영점 추정)은 `docs/E2_rules.md`에 있다. 맞춤 출력은 `docs/H6_fit_result.md`.

## 판정 (주 판정: 결합 맞춤, b 자유, 규칙 (ii)): **조화 + 라벨 예측(a = 0.382) 지지**
| T | zG\* | σ(zG\*) | s(T) = dzG\*/dT (CC 사슬) | σ_s |
| --- | --- | --- | --- | --- |
| 0.100 | 1.0408 | 0.0011 | 0.423 | 0.011 |
| 0.125 | 1.0505 | 0.0028 | 0.423 | 0.023 |
| 0.150 | 1.0623 | 0.0008 | 0.438 | 0.006 |
| 0.175 | 1.0729 | 0.045 | 0.444 | 0.264 |
| 0.200 | 1.0901 | 0.214 | 0.464(외삽) | 1.15 |
- **결합 맞춤: a = 0.392 ± 0.010, b = 0.15 ± 0.05.** 세 예측 중 1σ 구간(0.382–0.402)에 들어가는 것은 0.382뿐이다(경계: 차이 0.010이 σ와 같다). 0.224와 0.158은 σ의 17배, 23배 떨어져 **기각**된다. 규칙 (ii)에 따라 '조화 + 라벨 지지'.
- 보조(판정에 쓰지 않음): 판 공존만 b 자유: a = 0.392 ± 0.034(0.382 포함); 판 공존만 b = 0: a = 0.413 ± 0.005 → 어느 예측도 1σ 안에 없지만, b = 0 가정은 결합 맞춤의 b = 0.15 ± 0.05와 3σ 어긋나므로 이 맞춤은 근거가 약하다.
- s(T) 자체가 T와 함께 커진다(0.423 → 0.438, T = 0.10 → 0.15): s = a + 2bT에서 b ≈ 0.15, 절편 a ≈ 0.39와 일관된다. 이는 사슬(열역학량)만으로 얻은 독립된 기울기이며 판 공존의 영점과 같은 방향이다.

## 한계와 주의
1. **T = 0.175, 0.20의 영점이 불안정하다.** 이 온도에서 영점 zG\*가 1.073, 1.084–1.090으로 스캔 범위(상한 1.100) 가장자리에 가까워 양의 v 쪽에 점이 적고, 부트스트랩 재표집에서 직선 맞춤이 외삽해 σ가 0.045, 0.214로 부풀었다(분포의 16–84%는 1.0709–1.0743, 1.0835–1.1055). 결합 맞춤에서 이 두 점의 가중치는 사실상 0이라 결과는 T = 0.10–0.15가 정한다. T = 0.20에서는 CC 사슬의 zG 범위(1.02–1.08)를 벗어난 외삽도 표시했다. 상한을 1.12로 늘린 재스캔은 지금 하지 않았다(보강이 필요하면 제안).
2. **T = 0.10은 영점 추정 창(0.2)을 정할 때 본 자료**라서, 그 점은 독립 시험이 아니다. 나머지 네 온도는 창 설정 후 처음 분석했다.
3. 예측 0.382, 0.224, 0.158은 T → 0 극한 기울기다. 결합 맞춤은 T = 0.10–0.15의 자료에서 b = 0.15를 두고 T → 0으로 외삽한 값이므로, b의 오차(± 0.05)와 고차항의 영향이 a에 들어 있다.
4. 시드가 세 개이고 판 크기가 하나(L = 24)라 크기 효과는 보지 않았다. 계면 핀 고정은 관찰되지 않았다(모든 실행이 한쪽 상으로 끝까지 이동).
5. 차이 0.010 ≈ 1σ는 규칙 (ii)의 경계다. 판정은 민감도 표 전체에서 같다.
