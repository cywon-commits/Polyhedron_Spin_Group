# M4 1단계 3층 보고 — 3D L = 12, 2D L = 32 완료 (61개 실행, 1단계 계산 종료)

3층(의뢰서 2-2 축소 범위)이 끝났다. 시작 전 조건(체크포인트 재개 테스트), 결정 1–3 반영, 2층 보고의 정정, B 3D zH₄ = 1.0 L = 10 재실행은 `docs/M4_stage1_tier3_prep.md`에 있다. 여기서는 3층 결과를 **사전 규칙으로 판정한 것**과 **규칙과 상관없는 정성적 관찰**을 구분해서 쓴다. **T = 0 해석값과 모순되는 결과는 없다.** 실행 방식은 의뢰서 2-3대로 대화를 이어 가며 모니터링했고, 컨테이너 재시작이 한 번 있어 3D L = 12 zG = 1.0이 처음부터 다시 돌았다(체크포인트가 저장되기 전이었다. 이 실행에서 `resumed from checkpoint`는 나오지 않았다). 3층의 다른 실행은 재개 없이 한 번에 끝났다.

## 1. 시작 전 조건과 정정 요약 (자세히는 prep 보고)
- 체크포인트 재개 테스트: 통과(PT, 교환 없는 사슬, 2D/3D, 여러 번 중단, SIGKILL). 체크포인트 쓰기는 원자적으로 바꿨고, 재개 줄은 로그와 HDF5(`resumed_at_blocks`)에 남는다. 2층 3D zH₄ = 2 가열 실행은 `wall_seconds`로 보아 체크포인트에서 재개된 것으로 판단한다(간접 증거).
- 2층 보고의 오류 두 가지(ΔBIC 버그, B 3D zH₄ = 1.0 냉각 T_down 인공값) 정정, B 3D zH₄ = 1.0 L = 8, 10 냉각 재실행: T_down = 0.309, 0.300 vs T_up = 0.370, 가열·냉각 창 0.061 → 0.070.

## 2. H1 (3D A, T 상 전이 차수)
3D L = 8, 10, 12, 점마다 0.9–1.1 T_peak 좁은 사다리(L = 12: 복제본 25–27개, 총 6.2만 스윕). PT 상태: L = 12는 교환율 최소 0.27, 0.29, 0.32, 왕복 16, 27, 29회로 의뢰서 목표(≥ 0.2, ≥ 10회)를 모두 만족한다. L = 10은 왕복 5–6회(2층 보고대로)라 아래 L = 10 값의 오차는 크다.

| zG | L = 8 / 10 / 12 의 c_peak (잭나이프 오차) | T_peak (L = 8 / 10 / 12) | 지수 a (c ∝ N^a, 전체 L) | 짝별 a (8→10, 10→12) |
| --- | --- | --- | --- | --- |
| 0.5 | 26.5 (1.2) / 36.8 (2.4) / 52.9 (3.5) | 0.1465 / 0.1479 / 0.1471 | **0.56** [0.50, 0.63] | 0.49, 0.67 |
| 1.0 | 32.6 (1.4) / 35.4 (3.1) / 40.0 (1.7) | 0.2478 / 0.2490 / 0.2485 | **0.17** [0.12, 0.21] | 0.12, 0.22 |
| 1.5 | 23.7 (1.3) / 26.5 (1.1) / 29.1 (1.2) | 0.3306 / 0.3366 / 0.3389 | **0.17** [0.11, 0.23] | 0.17, 0.17 |
(오차: c_peak마다 블록 잭나이프(블록 길이 ≥ 20 τ_E), 구간은 c_i ~ Normal(c_i, err_i)로 4000번 다시 맞춘 68% 구간. 최댓값 선택으로 c_peak에 작은 양의 편향이 있다. `tools/h1_scaling.py`, `docs/h1_scaling_tier3.md`.)

**사전 규칙에 따른 판정**
- 이중봉우리(보정된 세 조건, 의뢰서 결정 3): 3D 9개 PT 실행 모두 "이중봉우리 아님". 보정 ΔBIC는 −7.3 ~ −18.3(> 10 아님)이고 골 비율은 모두 1.00. 조건 (3)도 세 점 모두 만족하지 않는다: |2/3 − V_min|이 L = 8, 10, 12에서 줄어든다(zG = 1.0: 2.08, 1.25, 0.81 × 10⁻³; zG = 0.5: 6.2, 4.5, 3.6 × 10⁻⁴; zG = 1.5: 2.8, 1.7, 1.1 × 10⁻³). L = 12의 보정 ΔBIC: −10.5, −16.2, −18.0 (`docs/tier2_bimodality.md`).
- 비열 피크가 N에 비례하는가: **zG = 1.0, 1.5는 a ≈ 0.17로 1이 아니다**. 따라서 이 두 점에서 1차 전이의 증거는 없다.
- **zG = 0.5는 판정 불가로 둔다.** a = 0.56은 1이 아니고 이중봉우리도 없지만, 짝별 지수가 0.49 → 0.67로 L과 함께 커지고 있다(L = 10의 왕복이 6회뿐이라 그 값의 불확실성이 크다). 이 점이 L이 더 커지면 N에 비례(a → 1)하는지는 L = 8–12로 판정할 수 없다. 로컬 문서에서 H1의 정량 문턱을 찾지 못했다(찾은 것은 "비열 피크가 N에 비례하는 경향이나 이중 봉우리"라는 정성적 문구뿐). 기존 의뢰서에 수치 문턱이 있다면 알려 주면 그 값으로 재판정한다.

**정성적 관찰 (규칙이 아님)**
- 에너지 누적량 편차의 L 의존성은 N^(−0.45 ~ −0.8) 정도로 줄어든다(위 값에서 직접 계산). 1차 전이에서는 이 편차가 일정한 값으로 수렴하므로 연속 전이 쪽과 같은 방향이다.
- T_peak는 L에 따라 거의 변하지 않는다(zG = 1.5만 0.3306 → 0.3389, +2.5%).
- 결함 f_ud가 전이점에서 0.26–0.49(거칠게 보기), 0.66–0.96(플라켓)이라 결함 매개 여부는 3D에서 판정하지 않는다(의뢰서 결정 1: 3D에는 이분법을 적용하지 않는다).

## 3. H2 (2D A zG = 1.0)
2D L = 16, 24, 32, T_peak = 0.2204, 0.2167, 0.2142(L이 커지면 약간 낮아짐). PT: L = 32는 R = 68, 교환율 최소 0.26, 왕복 29회. c_peak = 21.5, 25.0, 23.1 — **L = 16–32에서 증가하지 않는다**(지수는 의미가 없다).

### 3.1 사전 규칙: R_b = ρ(b = 4)/ρ(b = 2) (의뢰서 결정 1) → 판정 불가
| 크기 | T_c | R_b(0.9 T_c) | f_ud(b = 4) | R_b(1.1 T_c) | f_ud(b = 4) | 쓸 수 있는가 | 크기별 판정 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| L = 24 | 0.2167 | 0.00 | 0.001 | 0.19 | **0.74** | 0.9 T_c만 | 판정 불가 |
| L = 32 | 0.2142 | 0.00 | 0.002 | 0.22 | **0.72** | 0.9 T_c만 | 판정 불가 |
- 결합 판정(L = 24, 32 모두): **판정 불가**. 이유: ① 1.1 T_c에서 b = 4 거칠게 보기의 f_ud가 0.72–0.74라 의뢰서의 "f_ud < 0.1인 온도에서만 쓴다" 조건에 걸려 R_b(1.1 T_c)를 쓸 수 없다. 규칙의 "해방"과 "해방 없음"은 모두 이 값을 요구한다. ② R_b(0.9 T_c)는 쓸 수 있지만 0.0이다(0.9 T_c에서 b = 2, 4 모두 결함 밀도가 사실상 0). 사전 규칙을 바꾸지 않았다.
- f_ud(b = 4)가 0.1을 넘는 온도: L = 24는 T/T_c ≈ 0.99–1.0 부근(0.03 → 0.26), L = 32는 T/T_c ≈ 0.97–1.0(0.02 → 0.13 → 0.39). 즉 b = 4 검출기는 T_c 바로 위에서 이미 못 쓴다.
- **정성적 관찰(규칙이 아님)**: 쓸 수 있는 구간(f_ud(b = 4) < 0.1, 즉 T ≲ T_c)에서 R_b는 0 → 0.17–0.24(L = 24: 0.24, 0.34; L = 32: 0.17, 0.20, 0.41)로 올라가고 어디서도 0.7에 가깝지 않다. 이 값만으로는 규칙의 "해방 없음"(R_b(1.1 T_c) < 0.5)을 뒷받침하는 것도 반박하는 것도 아니다(1.1 T_c의 값을 못 쓰므로). 해석 근거(결합 쌍 비율)도 이 구간에서는 쓸 수 없다.

### 3.2 m₃의 L 의존성과 G₃(r)의 형태 (L = 16, 24, 32; `tools/m3_decay.py`, `docs/m3_decay_tier3.md`)
| T/T_c | m₃ (L = 16 / 24 / 32) | 국소 지수 −d ln m₃/d ln L (24→32) |
| --- | --- | --- |
| 0.7 | 0.5634 / 0.5534 / 0.5470 | 0.04 |
| 0.9 | 0.4626 / 0.4529 / 0.4462 | 0.05 |
| 1.0 | 0.3044 / 0.2717 / 0.2686 | 0.04 |
| 1.1 | 0.1398 / 0.1026 / 0.0820 | 0.78 |
| 1.3 | 0.0810 / 0.0561 / 0.0432 | 0.91 |
- 상관함수 G₃(r)(r = 1…L/2, 주기 영상 포함) 맞춤: **T/T_c = 0.7–1.0에서 거듭제곱 감쇠가 지수 감쇠보다 로그 공간 평균제곱오차가 한두 자릿수 작다**(예: T/T_c = 0.7, L = 32: 3.9 × 10⁻⁶ 대 5.0 × 10⁻⁴). 지수 η는 L에 거의 무관하다: 0.7에서 0.23, 0.23, 0.21; 0.8에서 0.30, 0.27, 0.26; 0.9에서 0.36, 0.37, 0.34(L = 16, 24, 32), 1.0에서는 0.79, 0.81, 0.72. T/T_c = 1.1에서는 지수 감쇠가 낫다(ξ ≈ 1.9–2.8).
- 지수 감쇠 맞춤의 ξ는 T < T_c에서 L에 비례한다(0.7에서 10.7, 15.4, 21.2) — 유한한 상관길이가 아니라 "계 크기보다 긴" 감쇠를 뜻한다.
- 한계: (a) G₃(r)의 표본별 오차를 저장하지 않아(합만 저장) 가중 없는 맞춤이므로 MSE 비는 서술적이지 통계 검정이 아니다. (b) **m₃의 국소 지수(0.03–0.05)는 순수 거듭제곱이면 η/2(0.10–0.18)와 같아야 하는데 약 1/3이다.** 맞춤 범위(r ≤ L/2), 단거리 성분, 겉보기 η의 T 의존성 등 원인을 확인하지 못했다. 따라서 "T_c 아래가 준장거리질서(거듭제곱)"라는 해석은 **정성적 관찰**로만 기록하고 결론으로 쓰지 않는다. 비열 피크가 L = 16–32에서 늘지 않는 것(21.5, 25.0, 23.1)과 같은 방향이지만 정의된 판정이 아니다.

## 4. T_c/zG의 크기 의존성 (`docs/figures/stage1/tc_over_zg.png`, `docs/tc_over_zg_tier3.md`)
| 구분 | zG = 0.5 | 1.0 | 1.5 |
| --- | --- | --- | --- |
| 3D T_c/zG (L = 8 / 10 / 12) | 0.293 / 0.296 / 0.294 | 0.248 / 0.249 / 0.249 | 0.220 / 0.224 / 0.226 |
| 2D T_c/zG (L = 16 / 24) | 0.257 / 0.254 | 0.220 / 0.217 (L = 32: 0.214) | 0.193 / 0.193 |
- T_c/zG는 zG가 커질수록 줄어든다(3D L = 12: 0.294 → 0.249 → 0.226; 2D L = 24: 0.254 → 0.217 → 0.193). T_c는 zG에 대해 선형(T_c ∝ zG)이 아니다.
- 평균장형 비교: T_c/(zG ⟨m₃⟩²), ⟨m₃⟩은 T = 0.02 냉각 사슬 값(0.71–0.73; 3D L = 12는 냉각 사슬이 없어 같은 점의 L = 8, 10 평균). 3D L = 12에서 0.571, 0.467, 0.419; 2D L = 24에서 0.508, 0.413, 0.361. 이 정규화도 zG와 함께 줄어들고 상수가 아니므로 단순한 T_c ∝ zG⟨q₃⟩²는 성립하지 않는다. (이 정규화는 의뢰서에 주어진 정의가 아니라 내가 정한 것이다.)

## 5. 규칙 판정과 정성적 관찰의 구분 (요약)
| 항목 | 사전 규칙의 결과 | 정성적 관찰 |
| --- | --- | --- |
| H1 이중봉우리 (3D 9개 실행) | 아님(전부) | V 편차가 N^(−0.45~−0.8)로 줄어듦 |
| H1 c_peak ∝ N | zG = 1.0, 1.5 아님; zG = 0.5 판정 불가 | zG = 0.5의 짝별 지수가 0.49 → 0.67로 증가 |
| H2 R_b 규칙 (2D L = 24, 32) | 판정 불가(1.1 T_c의 값을 쓸 수 없음) | 쓸 수 있는 구간에서 R_b ≤ 0.41 |
| H2 m₃ 감쇠 | (사전 규칙 없음) | G₃가 T < T_c에서 거듭제곱 쪽이 훨씬 잘 맞음, 단 m₃ L 지수와 η가 맞지 않음 |
규칙을 바꿔야 한다고 판단한 항목은 없다. 아래 결정 사항에 올린 것은 규칙 변경 제안이 아니라 추가 자료나 별도 통계에 대한 제안이다.
