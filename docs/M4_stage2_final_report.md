# M4 2단계 최종 보고

## 2. 예상과 달랐던 점
1. **재진입 규칙의 설계 오류**: 양쪽 사다리에서 F → C가 보일 것을 요구했지만 C–F가 1차라 준안정이 크다(가열 과열 +0.08, 냉각은 T = 0.12까지 C). 평형 T_re는 판 공존으로 잰 것이 맞다.
2. **H6 경계의 정체**: M2가 평형 상이므로 C|F 판의 영점은 C–F 직접 경계가 아니라 F|M2 경계다(T_re 0.2300 ≈ T₁ 0.2324). a = 0.392는 F|M2 조화 + 라벨 예측 0.390과 일치, C|F 직접 예측 0.382와는 보조 맞춤에서 1.1σ 차이. 판정은 불변, 해석만 추가.
3. **3D U 점 규칙 구간의 크기 의존성**: L = 8 → 10에서 구간 상단이 거의 같다(0.140 → 0.143, 0.176 → 0.177). 2D L = 16 때와 달리 상에 관한 진술이 가능하나 크기는 둘뿐이다.
4. **zG = 0.3 탐색**: 삼중임계점 가설을 지지하지 않음(a(8 → 10) = 0.26, 이중봉우리 없음, 단조 추세 아님). 크기 둘, 오차 평가 없음 → 기각도 아님(`A03_exploratory.md`).
5. **B 3D T_c의 크기 의존성**: L = 12 → 16에서 0.0020 낮아짐(통계 오차의 약 4배).

## 3. 방법·도구 알림 (오류와 수정 기록)
- **판 공존 절차**: 보폭 조정을 판 위에서 돌려 계면이 움직임, 후반 80% 속도가 포화 → 복사본 조정과 초기 과도 구간 속도로 교체(T = 0.10 첫 스캔에서 발견, 원 결과와 일치 확인).
- **영점 추정 사후 변경(두 번)**: 전체 직선 → 영점 양쪽 국소 맞춤, 시드 재표집과 창 체계 오차 추가. T = 0.10은 독립 시험이 아님. 민감도(여섯 방식에서 a = 0.384–0.392)는 `H6_result.md`. **논문 방법 절에 반드시 밝힌다.**
- **오차 추정기 원칙 변경(Oct 16)**: 영점 오차의 주 추정량을 σ_std에서 백분위 반폭으로 바꿨다(앞으로 적용, 소급 없음; H6와 2D 쐐기 기록은 그대로).
- **추정기 약점(이번에 확인, 사후 변경 안 함)**: 한쪽 창 안 서로 다른 T가 2개 미만이면 첫 부호 변화 보간으로 되돌아가 시드 잡음 부호를 집는다. T 스캔(동일 T에 시드 여러 개)에서 영점이 격자점에 붙고 σ가 한쪽으로 부풀 수 있다. 다음 사전 규칙의 후보: 시드 평균 곡선의 국소 맞춤 + 시드 재표집.
- ΔBIC 계산의 누락 인자 수정, 스퓨리어스 B 3D zH₄ = 1.0 T_down 재실행, 체크포인트 구성 불일치 복구, 파이프라인 대기 스크립트 자기 일치, 테스트 실패 상태 커밋 2회(즉시 수정) — 각 보고서에 기록.
- **실행 환경**: 컨테이너가 반복 재시작되어 3D U 점과 판 스캔이 여러 번 처음부터 다시 돌았다(결과에는 영향 없음; 체크포인트 이어 달리기는 재시작 전에 쌓인 구간이 있을 때만 작동). 데이터는 실행이 끝날 때마다 커밋했다.

## 4. 한계
- 3D 쐐기와 H5의 3D 결과는 L = 12(쐐기), L = 8, 10(H5)로 크기 의존성이 거의 검증되지 않았다. 3D T₂는 한 번만 측정했고(원 측정, 시드 3개), T₁ 보완 측정은 T₂를 재측정하지 않았다.
- B 3D T_c, 잠열은 두 크기(L = 12, 16)의 값이다. 열역학 극한은 외삽하지 않았다.
- H2는 판정 불가(1단계 기록), H1은 3개 점에서 연속과 일관(1단계). 2단계에서 바뀌지 않았다.
- 모든 해석 예측은 조화 + 라벨 엔트로피의 T → 0 근사이다. 쐐기 위치의 −0.004~−0.015 차이는 비조화 보정으로 보이나 계산하지 않았다.
