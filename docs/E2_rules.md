# E′ (K = −0.25, zH₄ = 0.25) 1차 범위: 판정 규칙 (실행 전에 고정, Oct 13)

사용자 결정(2단계 결정 2)에 따라 계산 전에 고정한다. 구현은 `polyspin/analysis/e2_rules.py`(단위 테스트 포함). 결과를 본 뒤 바꾸지 않는다. 범위: 2D L = 16, 24, 3D L = 8, 10, zG = 0.9, 1.0 (정렬 시작, 좁힌 사다리). 크기 추가(2D L = 32, 3D L = 12)는 이 결과를 보고 결정한다.

## H7 (잔류 nematic, 두 전이의 분리)
- T₁ = χ₁(m₁ 감수율) 피크 온도, T₂ = χ₂(m₂ 감수율) 피크 온도(사용자 규칙의 "χ₂ 또는 비열 피크" 중 χ₂로 고정; 비열 피크는 참고로 함께 보고).
- 판정: **모든 크기에서 T₂ − T₁ > 3σ이고, 가장 작은 L에서 가장 큰 L로 갈 때 간격이 30% 넘게 줄지 않으면(간격(L_max) ≥ 0.7 × 간격(L_min)) '분리 지지'**, 그 외 '판정 불가'.
- **세부(규칙 고정 시 내가 정한 것)**: χ_l(T) = N(⟨m_l²⟩ − ⟨m_l⟩²)/T. 피크 위치는 최댓값 주변 세 점의 포물선 보간(내부 극대일 때만; 가장자리면 그 온도). σ² = 시간 블록 10개 delete-one 잭나이프의 피크 위치 분산 + (국소 사다리 간격)²/12.

## H12 (C → D 전이의 차수)
- 기존 H1 규칙을 T₁에 적용한다(사용자 규칙: "기존 규칙(보정 이중봉우리, 짝별 지수 a ≤ 0.7이면 연속과 일관, a ≥ 0.9 또는 이중봉우리면 1차)을 m₁에 그대로 적용"). 이름은 같지만 'm₁에 그대로'의 구현이 한 가지가 아니므로 **다음 해석으로 고정하고 결과 보고에 명시한다(사용자가 다르게 읽는다면 알려 주세요)**:
  - a: [0.85, 1.15] T₁ 구간 안에서 **비열 c(T)의 내부 극대 높이의 짝별 지수**(c_max ∝ N^a). 구간 안에 내부 극대가 없으면 a는 정의되지 않고 판정은 '판정 불가'(이중봉우리가 성립하면 1차).
  - 이중봉우리(세 조건 모두): 위 극대 온도에서의 에너지 시계열에 보정 ΔBIC > 10, 골 비율 < 0.9, 그리고 [0.85, 1.15] T₁ 구간의 V_min이 L과 함께 2/3에서 멀어짐.
  - 연속과 일관: a ≤ 0.7이고 |2/3 − V_min|이 큰 L에서 작은 L보다 작음. 1차: 이중봉우리 성립 또는 a ≥ 0.9. 그 외 판정 불가.
- 보편성류 식별은 **탐색적**으로만 한다(3D XY, Heisenberg, Ising의 β/ν와 ν가 L ≤ 12로는 구별되지 않음). 참고로 χ₁ 피크의 지수 γ/(dν)를 보고하되(3D XY 약 0.65, 2D KT η = 1/4이면 약 0.875, 1차 1) 판정에 쓰지 않는다.
- **2D 주의(사용자)**: n(RP² 시그마 모형)은 T > 0에서 진짜 질서가 없고 상관길이가 exp(c/T)로 커서 L ≤ 32에서는 KT형으로 보인다. η(T_c) ≈ 1/4가 나와도 'KT형 교차와 일관'으로만 기록한다.

## 추가 고정 (시험 실행 후, 본 계산 전; 내가 정한 세부)
- 시험 실행(2D L = 8, 3D L = 6, 0.02–0.6, 40개 온도)에서 **네마틱 m₂의 녹음(0.25 부근)에서 교환율이 0.00–0.02**(3D는 왕복 0회, 비열 피크 23–40)라서 B 절단선처럼 강한 1차 전이로 보인다. 한 사다리로 건널 수 없으므로 점·크기마다 **가열 사다리(정렬 시작, 0.5 T₁ ~ 1.12 T₂)와 냉각 사다리(무작위 시작, 0.9 T₂ ~ 1.5 T₂)**를 돌린다(T₁, T₂ 추정: zG = 0.9에서 0.097, 0.252; zG = 1.0에서 0.185, 0.252).
- 시험 실행의 χ 피크(참고): zG = 0.9: T₁ = 0.095–0.100, T₂ = 0.252; zG = 1.0: T₁ = 0.182–0.193, T₂ = 0.252–0.254 (간격 약 0.15, 0.07).
- **T₂의 정의(H7 판정용)**: 가열 사다리의 χ₂ 피크 온도 T₂ʰ(항상 정의)와, 냉각 사다리에 χ₂의 **내부** 극대가 있으면 그 온도 T₂ᶜ. 판정에는 **둘 중 낮은 값**을 T₂로 쓴다(가열 쪽은 과열 때문에 T₂가 높게 잡혀 간격이 커지는 쪽으로 치우친다. 낮은 값을 쓰면 '분리 지지'에 보수적이다). 두 값과 사용한 쪽을 보고한다.
- T₁은 가열 사다리의 χ₁ 피크(정렬 쪽 연속 영역; 냉각 사다리는 이 구간을 포함하지 않음).
- H12는 가열 사다리의 [0.85, 1.15] T₁ 구간에서 평가한다(T₁은 T₂ 아래의 정렬 상 안에 있어 교환이 작동한다).
- 계산량: 점 4개 × 크기 4개 × (가열, 냉각) 16개 실행, 추정 **12.4 h**(2D L = 16: 0.8 h, 2D L = 24: 4.3 h, 3D L = 8: 2.0 h, 3D L = 10: 5.4 h). 제안서의 "3–4 h"보다 크다: 제안서는 한 사다리를 가정했고 강한 1차 때문에 가열·냉각 두 사다리와 (L = 24, 10에서) 더 많은 복제본이 필요하다.

## H12 규칙 보강 (사용자 결정 Oct 15, 3D L = 12 실행 전에 코드(`polyspin/analysis/e2_rules.py`: `m_density`, `m_peak_structure`, `m_first_order`)와 테스트로 고정)
에너지 기반 규칙이 m₁ 전이에 둔감하므로 **m₁ 분포의 이중봉우리를 판정 조건에 추가**한다. 이번 E′ 1차 범위(16개 실행)의 판정은 바꾸지 않는다.
- **야코비안 보정**: m₁은 3성분 벡터라 질서가 없어도 |m₁| 분포가 작은 m에서 m² 때문에 억눌린다. 따라서 |m₁| 히스토그램을 그대로 쓰지 않고 **등방 밀도 P̃(m) = P(|m|)/m²**를 쓴다. 구현: 부피가 같은 껍질 구간(경계 m_max (k/n)^{1/3}, n = 18)으로 히스토그램을 만들어 구간당 개수가 P(|m|)/m²에 비례하게 한다(m = 0의 특이점 없음). m_max = 1.2 × (|m₁|의 99 백분위).
- **봉우리 구조(온도 하나에서)**: [1, 2, 1]/4로 평활한 뒤, 전체 최댓값의 25% 이상인 극대를 찾는다. '두 극대'는 **m = 0 쪽 극대(전체 구간의 아래 1/3 안)와 그보다 큰 m\*의 극대**가 있고, 그 사이 **골 비율 = 골/(두 극대 중 낮은 것) < 0.9**이며 **골의 깊이(낮은 극대 − 골)가 시간 블록 10개 delete-one 잭나이프 오차의 3배보다 클 때**다(내가 추가한 세부: 통계 잡음 극대 배제).
- **1차**: [0.85, 1.15] T₁ 구간에서 T₁(χ₁ 피크 온도)의 분포가 **모든 크기에서 두 극대**이고 **골 비율이 L이 커질수록 작아짐(골이 깊어짐)**.
- **연속과 일관**: P̃(m)의 극대가 하나(T₁ 위에서는 m ≈ 0, 아래에서는 m\*로 연속 이동).
- **결합**: 에너지 규칙(보정 이중봉우리 또는 a ≥ 0.9)과 이 규칙 **둘 중 하나라도 1차 조건을 만족하면 1차**, 아니면 기존 H12 판정(a ≤ 0.7과 V 편차 감소면 연속과 일관, 그 외 판정 불가).
- **소급**: 같은 규칙을 기존 E′ 자료(2D L = 16, 24, 3D L = 8, 10)에도 계산해 표로 남긴다(판정 변경이 아니며, 기존 판정과 다르게 나오면 그 사실만 보고하고 판정은 L = 12 결과와 함께 다시 정한다).
- 테스트(합성 분포): 등방 가우시안 벡터장(무질서), m\* n + 잡음(질서 연속), 0 근처 성분과 m\* 성분의 혼합(1차 공존)을 올바르게 분류하고, 골이 깊어지는 방향 조건을 확인한다.

## 3D L = 12 추가 실행 (사용자 결정 Oct 15)
3D L = 12, **zG = 1.0 한 점만**, H12용. **사다리는 0.8–1.2 T₁(T₁ ≈ 0.19이므로 약 0.152–0.228) 가열(정렬 시작)** 로 한정한다. 이 구간은 T₂(0.254)보다 아래라 교환 병목을 포함하지 않는다. H7은 두 크기로 판정이 끝났으므로 이 실행에서 T₂는 다루지 않는다. 판 공존 도구 구현과 병행한다.
