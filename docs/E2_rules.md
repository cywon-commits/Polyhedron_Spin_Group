# E′ (K = −0.25, zH₄ = 0.25) 1차 범위: 판정 규칙 (실행 전에 고정, Oct 13)

사용자 결정(2단계 결정 2)에 따라 계산 전에 고정한다. 구현은 `polyspin/analysis/e2_rules.py`(단위 테스트 포함). 결과를 본 뒤 바꾸지 않는다. 범위: 2D L = 16, 24, 3D L = 8, 10, zG = 0.9, 1.0 (정렬 시작, 좁힌 사다리). 크기 추가(2D L = 32, 3D L = 12)는 이 결과를 보고 결정한다.

## H7 (잔류 nematic, 두 전이의 분리)
- T₁ = χ₁(m₁ 감수율) 피크 온도, T₂ = χ₂(m₂ 감수율) 피크 온도(사용자 규칙의 "χ₂ 또는 비열 피크" 중 χ₂로 고정; 비열 피크는 참고로 함께 보고).
- 판정: **모든 크기에서 T₂ − T₁ > 3σ이고, 가장 작은 L에서 가장 큰 L로 갈 때 간격이 30% 넘게 줄지 않으면(간격(L_max) ≥ 0.7 × 간격(L_min)) '분리 지지'**, 그 외 '판정 불가'.
- **세부(규칙 고정 시 내가 정한 것)**: χ_l(T) = N(⟨m_l²⟩ − ⟨m_l⟩²)/T. 피크 위치는 최댓값 주변 세 점의 포물선 보간(내부 극대일 때만; 가장자리면 그 온도). σ² = 시간 블록 10개 delete-one 잭나이프의 피크 위치 분산 + (국소 사다리 간격)²/12.

## H12 (C → D 전이의 차수)
- 기존 H1 규칙을 T₁에 적용한다(사용자 규칙: "기존 규칙(보정 이중봉우리, 짝별 지수 a ≤ 0.7이면 연속과 일관, a ≥ 0.9 또는 이중봉우리면 1차)을 m₁에 그대로 적용"). 이름은 같지만 'm₁에 그대로'의 구현이 한 가지가 아니므로 **다음 해석으로 고정하고 결과 보고에 명시한다(사용자가 다르게 읽는다면 알려 주세요)**:
  - a: [0.85, 1.15] T₁ 구간 안에서 **비열 c(T)의 내부 극대 높이의 짝별 지수**(c_max ∝ N^a). 구간 안에 내부 극대가 없으면 a는 정의되지 않고 판정은 '판정 불가'(이중봉우리가 성립하면 1차).
  - 이중봉우리(세 조건 모두): 위 극대 온도에서의 에너지 시계열에 보정 ΔBIC > 10, 골 비율 < 0.9, 그리고 [0.85, 1.15] T₁ 구간의 V_min이 L과 함께 2/3에서 멀어짐.
  - 연속과 일관: a ≤ 0.7이고 |2/3 − V_min|이 큰 L에서 작은 L보다 작음. 1차: 이중봉우리 성립 또는 a ≥ 0.9. 그 외 판정 불가.
- 보편성류 식별은 **탐색적**으로만 한다(3D XY, Heisenberg, Ising의 β/ν와 ν가 L ≤ 12로는 구별되지 않음). 참고로 χ₁ 피크의 지수 γ/(dν)를 보고하되(3D XY 약 0.65, 2D KT η = 1/4이면 약 0.875, 1차 1) 판정에 쓰지 않는다.
- **2D 주의(사용자)**: n(RP² 시그마 모형)은 T > 0에서 진짜 질서가 없고 상관길이가 exp(c/T)로 커서 L ≤ 32에서는 KT형으로 보인다. η(T_c) ≈ 1/4가 나와도 'KT형 교차와 일관'으로만 기록한다.
