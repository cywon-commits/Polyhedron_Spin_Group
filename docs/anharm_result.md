## 이 판정이 말하는 것과 말하지 않는 것 (정성·한계)
1. **중심값의 이동은 일관되다**: 모든 경우에 보정이 쐐기를 낮은 T로 옮기고(T₁ −0.010, T₂ −0.010~−0.015 2D; −0.011, −0.012 3D) 측정 위치로 향한다. 2D T₁은 0.2333 대 0.2338로 거의 일치한다. 이는 앞서 본 해석 예측의 체계적 편차(−0.004 ~ −0.015)와 부호·크기가 같다.
2. **그러나 기준의 구별력이 낮다.** σ_pred가 3차 항 민감도 때문에 T₂에서 ±0.06까지 커서 기준 2σ(0.12)가 쐐기 폭(0.02)보다 훨씬 넓다. 3차 항을 넣으면 c가 1.1–1.7 → 0.5–1.1로 크게 변하고 2D에서는 Δc의 부호까지 바뀐다(M2 − F, zG = 1.1: +0.44 → −0.26). T = 0.08–0.24 범위는 T² 영역으로 보기엔 넓다는 뜻이며, '곡률 c'는 이 범위에서 잘 정의되지 않는다.
3. **맞춤 오차만 쓴 보조 계산(규칙 밖)**: σ_pred = T₁ 0.0005–0.0007, T₂ 0.0025–0.0036. 이 엄격한 기준에서 2D T₁, T₂와 3D T₂는 재현되지만 **3D T₁은 재현되지 않는다**(|차이| 0.0025 > 2σ = 0.0019).
4. **쐐기 폭**: 보정 후 폭은 2D 0.0167(조화만 0.0215, 측정 0.0222), 3D 0.0217(조화만 0.0225, 측정 0.0185). 폭은 사전 기준 항목이 아니며, 2D에서는 보정이 폭을 측정에서 멀어지게 했다(정성). 위치는 보정이 개선하고 폭은 보정이 개선하지 못한다.
5. b의 측정값은 2D(H6)뿐이다. 3D의 b 측정은 없고, 보정된 3D b₁ = 0.038–0.082는 예측으로만 남는다.
6. 사슬 크기는 2D L = 16, 3D L = 8 하나씩이고 쐐기 판은 2D L = 24, 3D L = 12다(크기 불일치).

## 결론 (논문용)
조화 + 라벨 자유에너지에 T² 보정을 더하면 H6의 곡률과 M2 쐐기의 위치가 사전 기준 안에서 재현된다(규칙 판정: 설명됨). 다만 곡률의 값이 맞춤 범위에 민감해(3차 항으로 부호까지 바뀜) 이 일치는 '비조화 보정이 방향과 크기 차수를 설명한다' 정도의 진술이며, 정량 검증이라고 쓰지 않는다. 구별력이 높은 시험은 T = 0.02–0.10의 낮은 구간에서 c를 따로 맞추는 것이다(미실시, 시간 추정 약 1 h; 결정에 올린다).
