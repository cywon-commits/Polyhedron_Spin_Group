# 후속 3 처리 보고 (M3 시작 전)

테스트 85개 모두 통과(`pytest`, 약 2분). M3는 아직 시작하지 않았다. 아래 결과 중 **의뢰서의 가정과 다른 점이 2건** 있어 먼저 적는다.

## 먼저 알릴 것

### 1. 모호성 여유(margin)만으로는 2π 와류를 완전히 걸러낼 수 없다
의뢰서 규칙(링크 여유 < 문턱 → '모호')을 구현했지만, 인공 2π 와류의 여유는 감기는 축에 따라 0 … 0.259로 퍼진다.
- 단일 플라켓에서 합법적인 이상적 `6±`류의 최소 여유는 **0.259**, `4`류는 0.271이다. 2π 와류가 C₃축 근처로 감기면 여유가 정확히 0.259로 **`6±`와 같아져서** 링크 수준 정보로는 구별이 불가능하다(링크당 90° 스텝이 120° 원소로 반올림되는 불일치 30°가 합법적 `6±`의 30° 스텝 불일치와 같기 때문).
- 무작위 축 4000개 시험(T 상, 단일 플라켓):

| 모호 문턱 | 걸러지지 않은 2π 와류 비율 | 걸러지지 않은 것이 읽힌 류 |
| --- | --- | --- |
| 0.10 | 62% | 6±만 |
| 0.20 | 29% | 6±만 |
| **0.25 (기본값)** | **5.5%** | 6±만 |

- 걸러지지 않은 2π 와류는 항상 `6+` 또는 `6−`로 읽히고 `2`로는 절대 읽히지 않는다. 따라서 **단일 플라켓의 `6±` 밀도에는 2π 와류의 오염이 상한 ~5%(문턱 0.25 기준) 섞일 수 있다.** 2π 와류는 에너지가 높아(의뢰서 기준 4) 평형에서 드물다고 보고, 이 오염은 보고서에 상한으로만 명시한다.
- 기본 문턱을 0.25로 둔 대가: 합법적 `6±`(0.259)와 `4`(0.271)가 문턱에 바짝 붙어 있어, 열요동이 있으면 이 류들도 상당수 '모호'로 빠질 수 있다. 이 손실은 `link_ambiguous_fraction`과 모호 플라켓 수로 온도별로 정량화된다. 실제 열적 배치에서의 최적 문턱은 M3 시험 실행에서 정하겠다(제안: 문턱 0.15–0.25 범위를 스캔).
- 구현 규칙(그대로 테스트로 고정됨):
  - 플라켓은 정확히 한 상태: **정의 불가**(맞춤 잔차 또는 겹침 < 0.9) / **모호**(정의되었으나 링크 여유 < 문턱) / **신뢰**.
  - D 상(Z₄)의 2π 와류는 겹침 0.71로 이미 '정의 불가'. T 상의 2π 와류는 겹침 0.93이 0.9 문턱을 통과해 `6−`로 오판정되지만 여유 0.22(< 0.25)로 '모호'가 된다. 여유 없이는 오염을 막지 못한다는 점도 테스트로 고정.
- **기본 보고류**: 신뢰 플라켓 중 `reportable_classes`(SU(2) 각 ≤ 180°): 2T는 `1, 4, 6±`, Z₄는 `1, 4±`. `2`, `3±`는 통계에서 제외하고 부가 진단으로만 둔다.
- **k = 2, 3 루프** (`Lattice.block_loops`, `block_census`): k = 3(6×6 블록 경계)에서는 2T의 모든 류가 모호 없이 정확히 검출된다. k = 2에서는 모든 류가 정확히 검출되지만 `2`류는 여유 0.22로 아직 '모호'다. 3D는 세 좌표 평면 모두 지원.
- 출력: `census`가 신뢰 플라켓의 류별 개수, 정의 불가 수, 모호 수, `link_ambiguous_fraction`(전체 링크 중 여유 < 문턱 비율), 단위 부피당 밀도를 낸다.

### 2. H6 예측에는 의뢰서의 식에 없는 항이 필요하고, 그 항이 더 크다
의뢰서의 ΔF_harm 식은 조화(스핀파) 항만 있다. 그런데 MC가 샘플링하는 것은 **라벨이 붙은 스핀**이므로 분배함수에는 스핀체마다 독립인 라벨 중복도가 들어간다: C(↑↑↓↓)는 6가지, M=2(↑↑↑↓)는 4가지, F는 1가지(스핀체마다 어떤 스핀을 뒤집을지 선택). 이는 정확하고 확장적(스핀체당 ln C(n,k))이며 조화항보다 크다. 그래서 둘 다 보고한다.

zG = J, K = 0.5, zH₄ = 1.5, 스핀체당 (F 기준, T 단위):

| 상태 | 조화 ΔF/T (2D, L_q = 96) | ln 라벨 중복 | **총 ΔF/T** (2D) | 총 ΔF/T (3D, L_q = 48) |
| --- | --- | --- | --- | --- |
| F (M=4) | 0 | 0 | 0 | 0 |
| M=2 | −0.953 | −1.386 | −2.340 | −2.333 |
| **C (M=0)** | **−1.266** | **−1.792** | **−3.058** | **−3.046** |

- **예측: 열요동은 C를 고른다.** 조화항만으로도 C가 가장 낮고(−1.27), 라벨 중복이 이를 −3.06으로 키운다. 자유에너지 순서는 F > M=2 > C. 3D(z = 6)도 거의 같다(−1.255 조화, −3.046 총).
- 부호는 (K, zH₄)에 대해 견고하다. (K, zH₄) = (0.5, 1.5), (0.5, 1.0), (0, 1.0), (1, 1.0), (−0.5, 1.0), (−1.5, 0)에서 모두 C가 최저(조화 ΔF/T −1.27 … −3.6). 일부 점(예: K = 0.5, zH₄ = 0.6)에서는 collinear 상태가 국소 최소가 아니어서 축퇴선 자체가 안정 영역이 아니다(코드가 오류로 알려 줌).
- **저온 경계 이동 예측**: F_C − F_F = 8(zG − J) + T·ΔF/T = 0 → **zG\*(T) = J + 0.38 T** (2D 0.382, 3D 0.381). 즉 C 영역이 zG = J를 넘어 F 쪽으로 확장된다. 조화 근사를 저온 외삽하면 zG = 1.1에서는 T ≈ 0.26에서 F → C의 엔트로피 구동 전이(재진입)가 예측되지만, 이 온도는 조화 근사의 신뢰 범위를 넘으므로 정성적 힌트로만 쓴다.
- 이 비교는 균일 상태끼리만 한 것이다. zG = J에서 비균일 상태(스핀체마다 M이 다른 상태)는 에너지가 (G/2)Σ(M_a − M_b)² ≥ 0만큼 높아 바닥상태 다양체에 들지 않음을 확인했다.
- 검증: 해석적 𝓗(q)를 작은 격자(4×4, 4×4×4)의 전체 격자 헤시안 유한차분과 비교(T, U, D, C, F 다섯 상, 128개 고유값 전부 2e-5 이내, 영모드 수 3 또는 2). 곡률항을 빼는 변이에서는 6개 테스트가 실패한다. q-격자 수렴: 2D L_q = 24 → 96에서 ΔF/T 변화 < 0.002. `n`은 매개변수라 n = 6의 H11에 그대로 쓸 수 있다.
- 한계: 이것은 조화 근사(O(T) 자유에너지)다. 비조화 보정은 O(T²)이고, 라벨 중복도는 정확하다. 판정은 절단선 D의 MC(PT)로 한다.

## 후속 3.1 처리 내용
- **C–D, D–F 해석 경계를 테스트에 추가**: `boundary_CD(J,K,zH₄) = (J − 2K + 4zH₄)/3`(Φ′(−1) = 0), `boundary_DF(J,K)`(zH₄ = 0, κ₄ = 0의 근). K = −0.5에서 0.6667과 1.0774(= (1 + √(4/3))/2)가 수치 바닥상태의 C/D, D/F 전환과 일치(±0.01에서 상이 바뀜). C–D 근방에서 순서변수 |M|/n이 √(zG − zG_c)로 시작함(거리 4배에 값 2배)도 확인했고, 이는 평균장 지수 1/2이다. 이 값을 확인한 점은 K = −0.5, −0.25, −0.75이며 zH₄는 0, 0.1, 0.25.
- **유한 온도 분류는 전역 질서변수로**: `global_class(m, m_thr)`가 m₁…m₄ 패턴만으로 T / C / M(U 또는 D, 알짜 모멘트) / F / 무질서를 나눈다. 스핀체별 문턱은 상 판별이 아니라 형태 진단에만 쓴다. 단, **U와 D는 m₁ 하나로는 구별되지 않는다**(M/n: U ≈ 0.23–0.25, D 0.05–0.45로 겹침). U/D 구별에는 형태 진단(분할 히스토그램에서 {211} 대 {22})이 필요하다. 절단선 E는 C–D–F를, 절단선 C는 T–U–F를 지나므로 한 절단선 안에서는 충돌하지 않는다.
- **H12**를 가설표에 기록했다(C → D 전이, 질서변수 M⊥, 3차 불변량 없음, 3D XY 보편성류 예상, 열린 질문). 판정은 m₁의 Binder 누적량 교차와 ν, γ/ν로 하며, 2D에서는 KT형 가능성을 함께 본다. (참고: T = 0 질서변수가 √ 시작하므로 평균장 수준에서는 연속이다.)
- 절단선 E(K = −0.5, zH₄ = 0, zG = 0.5, 0.8, 1.0, 1.2: C, D, D, F)를 계산 계획에 포함한다. 우선순위는 A, B 다음, C와 같은 수준. `configs/`에는 `run.py`와 함께 M3에서 넣는다.
