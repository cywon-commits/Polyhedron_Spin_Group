# M4 1단계 마감 보고와 2단계 제안

3층 결정(Oct 13)의 항목 1–5를 처리했다. 1단계 계산은 66개 실행으로 끝났다. 결과 순서: ① H1 zG = 0.5 L = 14 판정, ② B 3D zH₄ = 1.0 창 사슬(재가중이 불가능했다는 점 포함), ③ T_c 정규화 확인, ④ 1단계 한계 기록, ⑤ 2단계 제안(결정 필요 사항 포함).

## ① H1 (3D A zG = 0.5, L = 14) — 고정 규칙으로 "연속과 일관"
자세한 내용은 `docs/H1_L14_result.md`. 요약: 보정 규칙의 이중봉우리 성립하지 않음(보정 ΔBIC −10.4, 골 비율 1.00, |2/3 − V_min|이 L = 8–14에서 6.2 → 2.4 × 10⁻⁴로 감소), a(12→14) = 0.14(1σ 약 ± 0.24)로 규칙(≤ 0.7, 편차 감소)에 따라 **연속과 일관**. 짝별 지수 0.49, 0.67, 0.14가 단조롭지 않아 앞선 증가 추세는 통계 요동일 가능성이 크다. 이는 약한 1차를 배제한 것이 아니라 고정 문턱에서 1차 증거가 없다는 뜻이다.

## ② B 3D zH₄ = 1.0 창 사슬(0.300–0.370, 간격 0.005, 교환 없음, 정렬 시작과 무질서 시작): **재가중으로는 T_c를 정할 수 없다**
L = 8, 10에서 두 시작 모두 15개 온도, 4만 + 4만 스윕. 모든 사슬에서 정렬 ↔ 무질서 뒤집힘이 **0회**다(m₂ = 0.5 기준 부호 변화 횟수).

| 무질서 시작이 스스로 정렬한 최고 온도 / 무질서로 남은 최저 온도 | 0.305 / 0.310 | 0.300 / 0.305 |

- **정렬 상 분기와 무질서 분기의 e(T)가 L = 8과 L = 10에서 0.002 이내로 같다**(예: T = 0.340에서 정렬 −4.894 대 −4.892, 무질서 −2.563 대 −2.562). 창의 경계도 L에 거의 무관하다.
- 재가중(히스토그램 연결)은 한 사슬 안에서 두 분기를 오가야 쓸 수 있는데, 오가는 사슬이 없다. 각 분기의 에너지 히스토그램은 겹치지 않아(분기 간 차이 1.8–2.65 대 요동 0.02–0.1) 분기 사이의 자유에너지 차를 줄 수 없다. 따라서 **T_c와 잠열은 이 자료만으로 정해지지 않는다.** 결정 3에서 승인받은 방법은 적용되지 않았다.
- 사슬로 얻은 것: (a) T_c ∈ (0.310, 0.365)(두 분기가 모두 준안정으로 존재하는 창 안), (b) 잠열은 분기 에너지 차이로서 창 안에서 1.8–2.65/클러스터(T_c에서의 값은 미정), (c) 창이 T_c의 약 15%로 넓고 L에 무관 → 1차 전이의 직접 증거(H3 증거는 가열·냉각 창과 이 분기 에너지 차이로 기록; 비열 피크 값은 쓰지 않는다는 의뢰서 정정 그대로).
- T_c와 잠열을 실제로 정하려면 방법 전환이 필요하다(아래 결정 1).

## ④ 1단계 한계 기록 (사용자 결정)
1. **현재 검출기로는 2D 결함 해방(H2)을 판정할 수 없다.** b = 4 거칠게 보기 검출기는 0.97–1.0 T_c에서 이미 f_ud > 0.1이 되어 쓸 수 없고(L = 24: 0.99–1.0 T_c에서 0.03 → 0.26; L = 32: 0.97–1.0 T_c에서 0.02 → 0.13 → 0.39), R_b 사전 규칙은 L = 24, 32 모두 판정 불가다. R_b 탐색 통계(f_ud(b = 4) < 0.1인 가장 높은 온도에서의 R_b와 b = 2 밀도 곡선)는 2단계에서 **"탐색적"으로 표시**하고 H2 판정에는 쓰지 않는다.
2. **G₃(r)의 거듭제곱형 감쇠는 준장거리 질서로 해석하지 않는다.** 사용자 해석: SO(3)/T 시그마 모형은 점근 자유라서 상관길이가 ξ ~ exp(c/T)로 매우 크고, L ≤ 32에서는 거듭제곱처럼 보이는 유한 크기 교차 현상이 예상되며, η의 온도 의존성과 m₃ 지수 불일치도 이 해석과 일관된다. 정성적 관찰로만 남기고 판정에 쓰지 않는다. 측정기는 이제 `corr_blocks` 설정으로 G_l(r)의 블록별 값을 저장한다(블록 합이 전체와 같음을 테스트; `diagnostics: {corr_blocks: 10}`). 이미 끝난 1단계 실행에는 적용되지 않고 2단계 2D 실행에서 확인한다.
3. 모든 L ≥ 8 3D 연속 전이 후보에서 비열 최댓값만으로는 α/(dν)를 정하기 어렵다(c_peak 오차 5–10%). 지수 판정은 L ≥ 3개와 오차가 필요하다.

## ⑤ 2단계 제안 (우선순위는 사용자 결정대로: E′ → 판 공존 → C, D)
시간 추정은 `tools/stage_runner.py::hours`(4코어, 1단계 측정값). 규칙(문턱)은 승인 후 계산 전에 고정한다.

### 1순위: 절단선 E′ (K = −0.25, zH₄ = 0.25; T = 0 상: zG = 0.6 C, 0.9 D, 1.0 D, 1.1 F) — H12(C–D 연속, XY 예상)와 H7(잔류 nematic)
- 예비 결과(2D L = 8, M3): zG = 0.9에서 m₁이 T = 0.01의 0.22에서 0.19, 0.09, 0.05로 연속적으로 0이 되고 m₂ ≈ 0.9인 C로 넘어가며 C는 T ≈ 0.3에서 녹는다(비열 피크 23–26). 즉 **극성 질서(m₁)가 먼저 사라지고 nematic(m₂)이 남는** H7의 모양이다.
- 측정: m₁(T), m₂(T), 두 질서변수의 Binder 곡선, G₁(r)와 G₂(r)(블록 오차), 비열, τ. 계산은 점 zG = 0.9, 1.0을 주(主)로, zG = 0.6(순수 C 대조)과 1.1(F 재진입 대조)은 작은 크기만.
- 2D(KT 예상: η(T_c) = 1/4, 거듭제곱 감쇠 G₁)과 3D(XY 예상: β ≈ 0.35, ν ≈ 0.67)를 모두 본다. G₃에서 보았듯 L ≤ 32에서는 거듭제곱처럼 보이는 교차가 가능하므로 η를 단독 판정에 쓰지 않고 Binder 교차와 함께 본다.
- 단계: (a) 2D L = 16, 24 + 3D L = 8, 10, zG = 0.9, 1.0 (정렬 시작, 좁힌 사다리) 약 3–4 h; (b) 결과를 보고 2D L = 32, 3D L = 12를 추가(약 6 h). 점별 추정: 2D L = 16 0.2 h, L = 24 0.5 h, L = 32 2.5 h; 3D L = 8 0.5 h, L = 10 1.4 h, L = 12 0.8 h(좁은 사다리 기준; 이 점에서 사다리 폭은 예비 시험으로 정한다).

### 2순위: 판 공존 zG\*(T) 스캔 (H6 기울기 판별: 조화 + 라벨 0.382 / 라벨만 0.224 / 조화만 0.158)
- **먼저 알릴 식별성 한계**: 좁은 온도 구간에서는 zG\*(T) = J + aT + bT²의 a와 b가 퇴화한다. 계면 위치 오차 σ(zG\*) = 0.003, 0.005를 가정하면 σ(a)는
| 온도 | b를 함께 맞춤 | b = 0 가정 |
| --- | --- | --- |
| 0.15, 0.175, 0.20 | 0.09, 0.15 | 0.010, 0.016 |
| 0.10, 0.125, 0.15, 0.175, 0.20 | 0.05, 0.08 | 0.009, 0.015 |
  예측 사이 간격은 0.382 − 0.224 = 0.158, 0.224 − 0.158 = 0.066이다. b를 자유롭게 두면 σ(a) 0.05–0.15가 두 번째 간격(0.066)과 첫 번째 간격(0.158)에 비해 커서 판별이 안 되고, b = 0 가정에서만 판별된다(0.382 대 0.224는 σ(zG\*) ≤ 0.005에서 약 10σ, 0.224 대 0.158은 약 4σ). 즉 **판별에는 b의 크기를 따로 제한해야 한다**(고차 보정 b를 비교 가능한 두 번째 온도 구간으로 제한하거나, b를 자유롭게 두고 보고).
- 제안: T = 0.10, 0.125, 0.15, 0.175, 0.20(사용자 지정 0.15–0.20에 두 점 추가, 이유는 위 식별성), 대각선 계면(핀 고정 완화), zG를 0.005 간격 21개 값(1.00–1.10), 판 L = 24, 각 100k 스윕. 추정 약 2.5 h(계산) + 판정(영점 교차 보간 후 a, b 맞춤).
- 판정 규칙(승인 후 고정할 제안): (i) b 자유와 b = 0 두 맞춤을 모두 보고, (ii) a의 1σ 구간이 세 예측 중 하나만 포함하면 그 예측 지지, 둘 이상이면 판정 불가, 어느 것도 포함하지 않으면 예측 모두 기각, (iii) 계면이 움직이지 않는 zG(핀 고정)가 영점 교차 구간보다 넓으면 그 T는 제외.
