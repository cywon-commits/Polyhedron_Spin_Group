# M5 초안: 핵심 결과 세 묶음, 이론 절(n = 6 사다리), 방법 절, 한계 (Oct 17)

M4를 닫았다(근거: `docs/RESULTS_LEDGER.md`, `docs/M4_stage2_final_report.md`, `docs/anharm_result.md`). 이 문서는 M5(분석과 논문용 정리)의 첫 초안이며, 수치는 모두 장부와 보고서에서 가져왔다. 새로 계산한 것은 n = 6 사다리(§2)뿐이다.

## 1. 핵심 결과 세 묶음

### 묶음 A. 채널 선택 규칙
- E에서 C 스핀체끼리 결합 0(짝수 채널 K, zH₄와 홀수 채널 G가 분리된다는 구조의 출발점).
- E′과 D에서 **T₂(nematic 전이)가 zG와 무관**(2D, 3D 모두 zG = 0.9, 1.0에서 T₂ ≈ 0.240–0.254), T₁은 0.094 → 0.18로 크게 변한다. H7 분리 지지(네 점, 2D는 교차 온도의 분리로만).
- D 상의 결합 세기 ∝ G·M²(근사 비율 2.8, 측정 1.9). 논문의 핵심 그림 후보: E와 E′을 함께 보이는 T₁, T₂ 그림.
- H12(C → D)는 연속과 일관(네 점; 에너지 규칙 + m₁ 야코비안 보정 규칙).

### 묶음 B. 엔트로피 선택 (조화 + 라벨 자유에너지)
- **H6**: C–F 경계의 저온 기울기 a = 0.392 ± 0.010, b = 0.15 ± 0.05가 조화 + 라벨 예측 0.382를 지지(라벨만 0.224, 조화만 0.158 기각; 보조 재스캔 a = 0.390 ± 0.007). 논문의 핵심 정량 결과.
- **재진입 F → C(zG = 1.1)**: 평형 T_re = 0.2300 ± 0.0026(판 공존), 사전 예측 범위 0.21–0.26 안. 사다리 규칙('한쪽에서만 보임')은 설계 오류로 기록.
- **M2 쐐기(F → M2 → C)**: 해석 예측(조화 + 라벨) 후 판 공존으로 확인. 2D T₁ = 0.2324–0.2338, T₂ ≈ 0.250–0.256; 3D(L = 12) T₁ = 0.2356 ± 0.0008, T₂ = 0.2541 ± 0.0064(최종 규칙 판정: 쐐기 확인, 위치 일치, 여유 1.4배). H6가 잰 경계의 정체는 F\|M2.
- **비조화 보정(열역학 적분)**: 조화 + 라벨의 위치 편차(−0.004 ~ −0.015)를 해소해 쐐기 위치 네 항목이 측정 오차의 0.5–1.5배 안에서 재현된다(b는 0.054 대 0.15 ± 0.05, 경계 사례). 조화 + 라벨 + 분기 에너지 적분이 이 모형의 저온 상경계를 정량적으로 설명한다.

### 묶음 C. 군론 예측과 전이 차수
- **H1(T 상 팔중극 전이, l = 3에 3차 불변량 없음)**: zG = 0.5, 1.0, 1.5 모두 연속과 일관(이중봉우리 없음, a(12 → 14) ≈ 0.14–0.17, |2/3 − V_min| 감소). zG = 0.3 탐색은 삼중임계점 가설을 지지하지 않음(판정 아님).
- **H3·nematic 녹음(l = 2에 3차 불변량 있음 → 1차)**: B 3D zH₄ = 1.0 T_c = 0.356 ± 0.002(L = 12: 0.3573 ± 0.0005, L = 16: 0.3553 ± 0.0003, 크기 의존성 있음), 잠열 2.05 ± 0.03 /클러스터. nematic 녹음(T₂)은 약한 1차의 모습.
- 대조의 문장: l = 3 전이는 연속과 일관, l = 2 전이는 1차 — Landau 불변량 논증이 가리키는 방향과 같다.

## 2. 이론 절 (MC 없음): 공선 상태의 에너지–라벨 엔트로피 경쟁과 쐐기 사다리
공선 상태(k개의 스핀이 뒤집힘, 순모멘트 M = n − 2k)의 에너지는 E_k − E_F = x(n² − M²)/2 (x = zG − J)이고, 라벨 엔트로피는 ln C(n, k), 조화 항은 ½(logdet_k − logdet_F)이다. 따라서
ΔF_k/T = a_k u + δ_k, u = x/T, a_k = (n² − M²)/2, δ_k = ½(logdet_k − logdet_F) − ln C(n, k).
k번 상태가 평형 사다리에 있을 조건은 직선 a_k u + δ_k가 아래쪽 포락선에 있는 것이다. n = 4에서는 4δ_M2 < 3δ_C가 M2 쐐기의 조건이다.

**n = 6 계산**(`tools/n6_ladder.py`, 조화 코드의 n = 6 일반화, 같은 모형 족 K = 0.5, zH₄ = 1.5, 변수는 n = 4와 같다고 가정):
| 격자, zG | δ_M4, δ_M2, δ_C | 경계 x/T (내려가며): F → M4, M4 → M2, M2 → C | x = 0.1에서 T |
|---|---|---|---|
| 2D, 1.0 | −2.882, −4.437, −4.935 | 0.2882, 0.2592, 0.2489 | – |
| 2D, 1.1 | −3.030, −4.663, −5.185 | 0.3030, 0.2722, 0.2610 | 0.330, 0.367, 0.383 |
| 3D, 1.0 | −2.878, −4.428, −4.923 | 0.2878, 0.2583, 0.2478 | – |
| 3D, 1.1 | −3.025, −4.651, −5.171 | 0.3025, 0.2711, 0.2597 | 0.331, 0.369, 0.385 |
- **예측: n = 6에서 F → M4 → M2 → C 네 상이 모두 평형 사다리에 있다**(네 계산 모두). M4 폭 x/T ≈ 0.029, M2 폭 ≈ 0.010(zG = 1.0, 2D). n = 4(0.3899, 0.3592)와 같은 코드 결과가 이전 쐐기 값과 일치함을 확인했다.
- 정직한 제한: T → 0 조화 근사이며, n = 4에서 비조화 보정이 위치를 −0.01 이동시켰다(§1 묶음 B). n = 6 위치에도 비슷한 크기의 보정을 기대하지만 계산하지 않았다. n = 6 모형의 실제 변수는 의뢰서에 없어 n = 4와 같다고 가정했다. 판 공존 확인(Oct 18, 2D L = 24, zG = 1.1): **M4 상은 확인**(T_a = 0.3205 ± 0.0011, T_b = 0.3544 ± 0.0021), **M2 상은 분해되지 않음**(T_c = 0.3641 ± 0.0045; T_c − T_b = 0.0098 대 2σ 0.0099, 경계). 세 경계는 예측(0.3300, 0.3674, 0.3832)보다 −0.010 ~ −0.019 낮고 허용 ±0.03 안이다. 사전 판정은 '사다리 완전 확인 아님'이다(`docs/CD_rules.md`).

## 3. 방법 절 (그대로 밝힐 것)
1. **영점 추정 방식의 두 차례 사후 변경**: 전체 직선 맞춤 → 영점 양쪽 따로 국소 맞춤 → (오차에 시드 재표집과 창 선택 체계 오차 추가). T = 0.10은 창을 정할 때 본 자료이므로 독립 시험이 아니다. 민감도: 여섯 방식에서 H6 a = 0.384–0.392(모두 0.382를 1σ 안에 포함, 0.224, 0.158을 12σ 이상 배제). (`docs/H6_result.md`, `docs/E2_rules.md`)
2. **오차 추정기 원칙 변경(Oct 16)**: 영점 오차의 주 추정량을 표준편차에서 백분위 반폭으로. 앞으로 적용, H6와 2D 쐐기 기록에는 소급하지 않음.
3. **재진입 규칙의 설계 오류**와 보완 측정(C\|F 판 공존)의 위치: 규칙 판정(한쪽 사다리에서만 보임)은 바꾸지 않고 평형 T_re는 별도 보완 측정으로 기록.
4. **3D M2 쐐기 판정의 순서**: (i) 사전 규칙의 원 측정 판정 = 쐐기 불성립(σ_pct 0.0196, 첫 부호 변화 보간으로 되돌아가는 추정기의 약점), (ii) 보완 측정과 진단 맞춤 = 약점 진단 후속 결과, (iii) 시드 평균 추정기 규칙(재측정 전에 고정) 하나로 최종 판정 = 확인. M2 존재 결론은 시드 평균 곡선에 근거. 판정이 나올 때까지 다시 쟀다는 독해를 막기 위해 세 단계를 모두 적는다.
5. **비조화 보정의 두 판**: 다항식 판(구현 규칙 5/5, 의뢰서 문구 3/5)과 열역학 적분 판(5/5, 사전 고정, σ_예측은 통계 오차만). 기준 어긋남의 일부는 의뢰서가 σ_예측을 정의하지 않은 데 있었음을 밝힌다.
6. 판 공존 측정 절차의 오류와 수정(보폭 조정이 계면을 움직임, 후반 속도 포화), ΔBIC 계산의 누락 인자 수정, 실패한 테스트 커밋 2회와 즉시 수정, 컨테이너 재시작에 따른 재실행(체크포인트 재개 기록은 HDF5 `resumed_at_blocks`).

## 4. 판정 불가와 한계 정리
- **H2(2D 결함 해방)**: 판정 불가(b = 4 검출기가 0.97–1.0 T_c에서 쓸 수 없음). R_b는 탐색적.
- **2D의 교차 해석**: G₃(r)의 거듭제곱 감쇠, m₃의 L 의존, D 전이의 η ≈ 1/4는 KT형 교차와의 일관으로만 기록(2D에는 진짜 질서가 없음, 상관길이 exp(c/T)).
- **zG = 0.3 탐색**: 삼중임계점 가설 미지지, 기각도 아님(크기 둘, 오차 미평가).
- **크기 의존성이 두 크기로만 확인된 항목**: B 3D T_c(L = 12, 16), H5 3D(L = 8, 10), 3D M2 쐐기는 L = 12 한 크기.
- 비조화 적분의 b는 경계 사례, 사슬 크기와 판 크기의 불일치(2D L = 16 대 24, 3D L = 8 대 12), n = 6은 예측뿐.
- 모든 해석 예측의 기본은 조화 + 라벨의 T → 0 근사.
