# M4 2단계 후속 보고 (Oct 16 결정): 재진입 평형 T_re, H6 재스캔, M2 쐐기, B 3D 판 L = 16, 탐색 점 zG = 0.3

판정 기준은 모두 계산 전에 `docs/CD_rules.md`에 고정했다(Oct 16 절). 3D 절단선 C의 U 점(H5)은 아직 계산 중이라 결과가 끝난 뒤 이어서 보고한다.

## 1. 재진입 평형 T_re (C|F 판 공존 보완 측정, zG = 1.1, L = 24): **T_re = 0.2300 ± 0.0026 → 예측 범위(0.21–0.26) 안: "평형 재진입 온도 예측 확인(보완 측정)"**
- T = 0.200–0.270(0.005 간격), 시드 3개, 12000스윕: F 비율의 속도가 T ≤ 0.225에서 모든 시드가 양(F가 이김), T ≥ 0.240에서 모두 음, 0.230–0.235에서 부호가 바뀐다(최종 F 비율 1.0 → 0.0). 영점 0.2300 ± 0.0026(부트스트랩 σ 0.0026, 창 선택 체계 오차 0, 핀 고정 없음).
- H6 결합 맞춤(T = 0.10–0.20 자료)을 T_re까지 외삽한 예측 0.234 ± 0.008과 **0.5σ 안에서 일치**한다. 즉 H6 맞춤이 T = 0.20 위로 외삽에서도 성립한다.
- 재진입 판정("한쪽 사다리에서만 보임")은 바꾸지 않는다. 이 보완 측정은 규칙이 요구한 가열·냉각 관찰이 아니다.
- **규칙 설계의 문제(기록)**: 사전 고정한 재진입 규칙은 양쪽 사다리(가열, 냉각)에서 F → C가 모두 보이는 것을 요구했지만, C–F 경계가 1차라서 준안정이 크다는 점(가열 사다리는 과열 F, 냉각 사다리는 과냉각 C)을 고려하지 않았다. 실제로 L = 16 가열은 T_re = 0.316(평형값 +0.08), 냉각은 T = 0.12까지 C에 머물렀다. 평형 전이를 측정하지 못하게 설계된 규칙이다.

- **보조 재맞춤(재스캔 두 점으로 교체)**: a = 0.390 ± 0.007, b = 0.17 ± 0.03(`docs/H6_fit_rescan_aux.md`). 규칙 (ii)를 이 맞춤에 형식대로 적용하면 1σ 구간(0.383–0.397)에 **어느 예측도 들지 않는다**(0.382와의 차이 0.008 = 1.1σ). 라벨만(0.224)과 조화만(0.158)은 20σ 이상 기각이다. **H6 판정은 기존 결과(a = 0.392 ± 0.010 → 조화 + 라벨 지지)로 고정하고** 이 차이는 사실로만 보고한다. 아래 M2 쐐기가 이 값의 해석에 관련된다.

## 3. M2 쐐기 (F → M2 → C): 해석 계산이 예측, 판 공존이 위치를 확인
**해석 계산**(`docs/M2_wedge_analytic.md`, 조화 + 라벨 엔트로피, `polyspin/harmonic.py::selection`): 쐐기 조건 4δ_M2 < 3δ_C가 2D, 3D, zG = 1.0, 1.1 모두에서 성립한다 → 평형 M2 쐐기가 **예측된다**. 2D zG = 1.1에서 x/T ∈ (0.378, 0.411), 즉 **F → M2가 T₁ ≈ 0.243, M2 → C가 T₂ ≈ 0.265**. (zG = 1.0, T → 0: x/T ∈ (0.359, 0.390); C|F 직접 경계 0.382는 쐐기 안에 있다.)

**판 공존 확인**(zG = 1.1, L = 24, T 스캔 17점 × 시드 3개, 12000스윕):
| 계면 | 측정 | 영점 | 16–84% | 해석 예측 | 예측과 차이 |
| --- | --- | --- | --- | --- | --- |
| M2|F (F 비율) | T₁ | **0.2324** | 0.2317–0.2331 | 0.243 | −0.011 |
| C|M2 (M2 비율) | T₂ | **0.2500**(시드 평균 보간 0.2550) | 0.2426–0.2571 | 0.265 | −0.015(−0.010) |
- T₁: 모든 시드가 T = 0.230에서 양, 0.235에서 음. T₂: 모든 시드가 T ≤ 0.245에서 양(M2가 이김), T ≥ 0.260에서 음(C가 이김), 0.250–0.255에서 시드마다 갈린다.
- **직접 읽기**: T = 0.235–0.245에서는 M2가 F에 대해서도(M2|F 판에서 F 비율이 줄어든다) C에 대해서도(C|M2 판에서 M2 비율이 는다) 이긴다 → **M2가 가장 안정한 상인 온도 구간이 폭 약 0.02(0.2324 – 0.25)로 존재한다.** 해석이 예측한 폭 0.022와 일치한다.
- **사전 고정한 판정의 결과**: (a) **"위치 일치"(|T₁ − 0.243| ≤ 0.03, |T₂ − 0.265| ≤ 0.03): 성립.** (b) **"쐐기 확인"(T₁ < T₂이고 차이 > 두 영점 오차 합성의 2배): 문자 그대로 적용하면 성립하지 않는다.** 고정한 σ(부트스트랩 표준편차)는 T₁에서 0.132, T₂에서 0.54로 부풀었다. 한쪽 직선 맞춤이 점 두 개만으로 외삽하는 재표집이 약 3% 있어 표준편차에 꼬리가 생겼고(백분위 구간은 정상), 이 σ로는 차이 0.02가 2σ 아래가 된다. **규칙을 바꾸지 않고 결정 사항으로 올린다**(아래). 백분위 구간(T₁ 0.2317–0.2331, T₂ 0.2426–0.2571)은 겹치지 않고 위 직접 읽기는 시드별 부호로 확인되므로, 쐐기는 존재한다고 본다.
- 가열에서 보았던 M2 구간(T = 0.32–0.37, L = 16)은 평형 쐐기(0.23–0.25)의 위쪽에서의 준안정 연장(과열된 M2)이다.
- **H6와의 관계(해석)**: C|F 판에서 F 비율 영점은 M2가 있으면 F|M2 경계다. 실제로 C|F 판(zG = 1.1)의 T_re = 0.2300 ± 0.0026은 M2|F 판의 T₁ = 0.2324와 같다. H6 기울기 a = 0.392 ± 0.010(보조 0.390 ± 0.007)은 F|M2의 조화 + 라벨 예측 0.390(zG = 1.0, T → 0)과 일치하고, C|F 직접 예측 0.382와는 보조 맞춤에서 1.1σ 차이다. H6 판정(조화 + 라벨 계열 지지)은 그대로이고 경계의 정체가 F|M2라는 해석만 더해진다.

## 4. B 3D zH₄ = 1.0: 판 L = 16
| 판 크기 | T_c (속도 영점) | 
| --- | --- |
| L = 12 | 0.3573 ± 0.0005 |
| L = 16 | **0.3553 ± 0.0003** |
- 두 크기의 차이 0.0020은 통계 오차의 약 4배라 **T_c에 크기 의존성이 있다**(L이 커지면 낮아짐; 두 크기라 외삽하지 않았다). T_c = 0.356 ± 0.002(크기 효과 포함)로 기록한다.
- 잠열(L = 8, 10 창 사슬의 분기 에너지 차): T_c = 0.3553에서 2.07, 0.3573에서 2.03(L = 8, 10이 0.001 이내로 같다). **잠열 = 2.05 ± 0.03 /클러스터**로 기록한다.
- 준안정 비대칭(정렬 상은 +2%까지, 무질서 상은 −13%까지)과 L = 12 한 크기 한계는 이전 보고와 같고, 판 L = 16으로 한 크기 한계가 두 크기로 줄었다.
