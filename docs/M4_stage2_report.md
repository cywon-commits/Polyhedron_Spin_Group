## B 3D zH₄ = 1.0: T_c와 잠열 (구간으로 기록했던 값의 보강)
판 공존(정렬 | 무질서, L = 12, 평면 계면): 속도 v(T)의 영점 교차(초기 과도 구간 속도, 시드 3개, T = 0.350–0.366)와 시드 24개의 승패 비율 두 가지.
| 방법 | T_c |
| --- | --- |
| 속도 영점 (주) | **0.3573 ± 0.0005** (T ≤ 0.356에서 정렬이 자라고 ≥ 0.358에서 무질서가 이김; 0.356의 시드 변동이 큼) |
| 승패 비율(이전 방식, 4시드 × 6온도) | 0.3585 ± 0.0015 (정렬이 이긴 비율 100%, 75%, 75%, 25%, 25%, 0%: T = 0.356–0.361) |
- 두 방법이 0.001 이내에서 일치한다. 사슬로 얻었던 공존 창 (0.310, 0.365)은 T_c = 0.357–0.358 부근을 포함하고, 정렬 상은 T_c의 약 +2%(0.365)까지, 무질서 상은 −13%(0.31)까지 준안정으로 남는다 — 비대칭이며 과냉각이 크다.
- **잠열 e_무질서 − e_정렬 = 2.02 ± 0.03 /클러스터** (T_c = 0.3573; L = 8, 10 창 사슬의 분기 에너지; 두 크기가 0.002 이내로 같음). 이전 구간 1.8–2.65의 안이다.
- 한계: 판 크기가 하나(L = 12)다. 한 크기의 T_c이고 크기 의존성은 보지 않았다(정렬 상 분기 에너지의 L 무관성은 L = 8, 10에서 확인).

## 방법과 도구에 대한 알림 (오류, 수정)
1. **판 공존 측정 절차의 오류**: 처음 구현은 보폭 조정(`tune_steps`)을 판 위에서 직접 300스윕 돌려 기록 전에 계면이 움직였고, 속도를 후반 80%에서 재서 포화한 실행이 0으로 나왔다. T = 0.10 첫 스캔에서 발견했고(`zG* = nan`), 복사본에서 조정하고 초기 과도 구간 속도로 바꿔 다시 돌렸다. 처음 결과(결과 상태 기준 zG\*(0.10) ∈ (1.040, 1.045))는 새 결과 1.0408과 일치한다.
2. **영점 추정**: v(zG)의 기울기가 영점 양쪽에서 약 2배 달라 전체 직선 맞춤이 편향(1.0353)되어 영점 양쪽을 따로 맞추는 방식으로 바꿨다. T = 0.10을 본 뒤 정한 것이고 그 사실과 민감도(여섯 가지 추정에서 결합 맞춤 a = 0.384–0.392)를 `docs/H6_result.md`에 적었다.
3. 테스트가 실패한 상태로 두 번 커밋했다가 각각 바로 고쳐 푸시했다(원인: 합성 자료의 임계값 가정, 명령 연결에서 실패를 걸러내지 못함). 현재 전체 테스트가 통과한다.
4. 파이프라인 대기 스크립트가 모니터 명령 문자열과 일치해서 L = 12 종료 후 약 2.5시간 헛되이 기다렸다(대기 부분 삭제). 컨테이너 재시작으로 L = 12(블록 17346)와 E′ 두 실행이 체크포인트에서 재개되었다(기록은 각 보고서와 HDF5 `resumed_at_blocks`).

## 다음 범위 제안 (3순위: C, D, 탐색 점)
시간은 `tools/stage_runner.py::hours` 추정(4코어, 복제본 수는 비슷한 실행에서 가져온 대략값)이다.
| 계산 | 내용 | 추정 |
| --- | --- | --- |
| 절단선 C (K = 0, zH₄ = 0; zG = 0.6 T, 1.0 U, 1.2 U, 1.6 F), 2D L = 16, 24 | U는 정렬 시작 필수. F 쪽은 1차(가열·냉각 사다리) | L = 16 0.9 h, L = 24 6.1 h |
| 절단선 D (K = 0.5, zH₄ = 1.5; zG = 0.9 C, 1.0 축퇴, 1.1 F), 2D L = 16, 24 | H6와 같은 모형. F → C 재진입을 PT로 직접 봄 | L = 16 1.0 h, L = 24 7.0 h |
| 탐색 점 zG = 0.3 (3D L = 8, 10, A 절단선, 좁은 사다리) | T 상 전이의 삼중임계점 탐색(판정에 쓰지 않음) | 합 약 1 h |
- 권고: **C와 D는 2D L = 16으로 먼저(합 약 2 h)** 형태를 보고, L = 24는 결과를 보고 결정한다(합 13 h). 탐색 점은 L = 16이 끝난 뒤 같이 돌린다.
- R_b 탐색 통계(탐색적, H2 판정에 쓰지 않음)와 G₃(r)의 블록별 값(`corr_blocks`)은 이 범위의 2D 실행에서 함께 기록한다(이미 설정에 들어가 있다). E′ 2D 실행에는 결함 검출기가 해당 상(C, D)에서 켜지지 않아 R_b가 없다.
