## 먼저 알릴 것 (예상과 어긋난 결과 2건)

### 1. D 상은 L = G₁ = 0 물리 평면에 **존재한다** (후속 1.3의 전제와 다름)
의뢰서는 "K = 0, 0.5 탐색에서 미발견"이라 D가 없을 가능성이 높다고 했으나, K < 0까지 훑으면 D가 넓게 나온다.
- 위치: **K ≈ −1 … −0.1, zG ≈ 0.7 – 1.2, zH₄ ≲ 0.25** (그림 `docs/figures/D_phase_plane.png`).
  zH₄ = 0에서 K = −0.5이면 C(zG < 0.67) → D(0.68–1.06) → F(> 1.07). K = 0에서도 zH₄ = 0.25, zG = 1.06–1.12에 얇게 존재.
- 검증: K = −0.5, zG = 0.9, zH₄ = 0 등 세 점에서 무작위 시작 300개 + 구조 시작 20개로 전역 최소가 D({22}, 알짜 모멘트 있음).
  이량체 사이 각 145.2°, 161.2°, 127.6°, |M|/n = 0.30, 0.16, 0.44. 접선 헤시안은 전역 회전 영모드 3개를 빼고 모두 양수(엄밀한 국소 최소),
  차순위 상과의 에너지 차는 ≥ 0.03. 테스트 `test_D_phase_in_physical_plane`.
- **C–D는 연속**(이량체가 반평행에서 서서히 꺾이며 M/n이 0에서 증가), **D–F는 불연속**(M/n 0.36 → 1).
- 이전 M1의 상 분류기는 `|M|/n < 0.15`이면 C로 불러서 D의 일부를 C로 오분류할 수 있었다. 바닥상태 분류에서는 C를 M = 0(정확한 공선)으로 엄격히 정의하도록 고쳤다(`phase_of_gs(m_tol=1e-3)`). 유한 온도 분류의 문턱은 별도 매개변수로 남긴다.
- 따라서 후속 1.3의 "없으면 MC 범위에서 제외" 조건에 해당하지 않아 **제외하지 않았다**. 단, 새 절단선을 계산 계획에 넣는 일은 결정이 필요하다(아래 질문).
- 부수 관찰: C–F 축퇴선(zG = J)은 K < −1에서 D 없이 C와 F가 직접 만난다. K ∈ (−1, 0)에서는 D가 그 선을 덮으므로, "zG = J에서 C/F 축퇴"는 K ≥ 0 또는 zH₄ ≳ 0.5 영역의 성질이다.
- 확장 평면(L > 0 또는 사이트 간 사중극 결합)의 κ 공간 훑기에서도 D가 나온다(κ₄ > 0, κ₂ ≈ −3κ₄ 띠). 그러나 물리 평면에 이미 있으므로 확장은 필요 없다.

### 2. 단일 플라켓은 SU(2) 각이 큰 결함류를 구별하지 못한다
결합 변수를 "가장 가까운 2G 원소"로 반올림하므로, 링크 하나가 감당할 회전이 약 51°(겹침 0.9)를 넘으면 모호해진다.
플라켓은 링크 4개라서 감기는 각 α가 약 200°를 넘는 류가 문제다. 2T에서는 3개 류가 해당한다:
| 류 | α | 단일 플라켓 | 4×4 블록 경계(k = 2) |
| --- | --- | --- | --- |
| 1, 4, 6±  | 0°, 180°, 120° | 정확히 검출 | 정확히 검출 |
| 3±  | 240° | '정의 불가'(겹침 0.866 < 0.9) | 정확히 검출 |
| 2 (= −1, 2π 회전) | 360° | **6−으로 오판정**(겹침 0.929가 문턱 0.9를 넘음) | 정확히 검출 |

- 즉 `2`류는 문턱만으로는 걸러지지 않는다(정상인 `4`류의 겹침 0.924와 구별 불가). 플라켓 통계에서 `2`류와 `3±` 류의 밀도는 **신뢰할 수 없다**고 보고서에 명시해야 한다. 실제 열적 배치에서 이런 결함은 여러 플라켓에 퍼진 `4`류 쌍으로 보일 가능성이 높다.
- 대책으로 `holonomy`는 임의 길이의 닫힌 루프를 받는다(2×2 이상 블록 경계). 테스트 7은 이 한계를 반영해, 류마다 가능한 가장 작은 루프로 검증하고 한계 자체를 `test_single_plaquette_limit_documented`로 고정했다. 3D 결함선 길이는 플라켓 수이므로 같은 한계가 적용된다.
- 이것은 의뢰서 테스트 7("각 류가 코어 플라켓에서 정확히 나온다")의 문자 그대로의 요구를 **일부 류에서는 만족하지 못한다**는 뜻이다. 1, 4, 6±는 만족, 2와 3±는 k = 2 루프에서 만족.

## 후속 1 처리 결과
1. **테스트 4b (스핀 4개 상세 균형)** 완료. 스핀체 하나(J = 1, K = −1, 이량체 바닥상태), 단일 스핀 사슬 대 겹침 사슬의 E, A₂, A₃ 분포를 T/J = 0.05와 0.3에서 비교, KS 거리 ≈ 0.01(문턱 0.03).
   κ는 고정값(무작위 추첨 안 함)이라 제안밀도에 별도 분포가 없다.
   **변이 시험**(`tools/mutation_check.py`, 임시 복사본에서 실행, 대조군 통과 확인): (a) 제안밀도 비 제거, (b) 혼합 합 대신 성분 하나, (c) 중심 선택 가중치 1/(n−1) → 1/n, 세 변이 모두 테스트가 실패한다.
   참고: (c)는 T/J = 0.3에서만 잡힌다(0.05에서는 KS 0.018로 문턱 아래). 그래서 두 온도를 모두 쓴다.
2. **테스트 5b (저온 기울기)** 완료. T/J = 0.002–0.010 다섯 점에서 ⟨E⟩/N − E₀ = aT + bT² 가중 적합, L = 8(N = 64), 표는 `docs/lowT_slopes.md`.
   | 상 | 기울기 a | 오차 | 4와의 차 |
   | --- | --- | --- | --- |
   | T | 3.976 | 0.004 | −0.6% |
   | C | 3.987 | 0.003 | −0.3% |
   | F | 3.987 | 0.003 | −0.3% |
   | U | 3.977 | 0.004 | −0.6% |
   | D | 3.978 | 0.003 | −0.6% |
   모두 4.00과 1% 이내. **기울기가 4보다 작은 현상은 유한 크기 영모드로 정확히 설명된다**: 전역 회전은 에너지를 안 가지므로 a = 4 − n₀/(2N) (T, U, D는 회전 3개, 공선인 C와 F는 축 둘레 회전이 스핀을 안 움직여 2개).
   N = 36, 64, 144에서 T는 3.964, 3.976, 3.993으로 이 공식을 따라 4에 수렴한다(D는 3.978 → 3.988).
   **무른(조화 차수에서 평탄한) 모드는 어느 상에서도 없다.** C–F 축퇴점(zG = J, zH₄ = 1.5, K = 0.5)에서도 C와 F 모두 기울기 3.98–3.99로 같다.
   → H6의 order by disorder는 에너지 기울기로는 보이지 않는다. 조화 근사의 영점 진동 자유에너지 차(헤시안 고유값 로그합의 차)나 MC 자유에너지 비교가 필요하다.
3. **D 상 범위 정리**: 위 "예상과 어긋난 결과 1" 참조.

기타: 겹침 안정성 진단 `phi_prime1(κ) = Σκ_l l(l+1)/2`를 추가했고 F 바닥상태 점에서 Φ′(1) < 0임을 테스트로 확인했다(부분 겹침 U, D에는 적용되지 않는다는 점도 반영).

## 결정이 필요한 것
1. **D를 계산 계획에 넣을까?** 제안: 절단선 E = K = −0.5, zH₄ = 0, zG = 0.5(C), 0.8(D), 1.0(D), 1.2(F). C–D 연속 전이와 D–F 1차 전이를 모두 지나고, Z₄ 결함(Z₄ ≅ C₂의 2G)을 D에서 직접 볼 수 있다. D의 기준 배치로 인한 검출기는 이미 준비됐다.
2. 플라켓 결함 통계의 `2`류, `3±`류 한계를 어떻게 다룰까? 제안: 기본 보고는 신뢰 가능한 류(1, 4, 6±)만 하고, 나머지는 k = 2 루프 통계를 부가 진단으로 낸다.
