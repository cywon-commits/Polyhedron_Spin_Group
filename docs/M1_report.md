- `polyspin/` 패키지: `model`(해밀토니안·국소 ΔE·채널 형태 에너지), `moves`(단일 스핀, 강체 회전,

  `lattice`(2D/3D 주기 격자, 체커보드 부격자, 플라켓 목록), `groundstate`(L-BFGS 단일 스핀체 최소화),
  `observables`(m_l, 분할·상 분류).
- 구현 선택: Python + Numba. 이유는 의뢰서 기본값이며, 국소 ΔE 커널이 단순해 C++ 이득이 작고
  PT 복제본 병렬화는 numba `prange` + 복제본별 RNG로 충분하다.
- **겹침/분열 이동은 상세 균형을 맞춰 포함했다**(생략 아님). 제안분포 = ½ 구면 균등 + ½ 같은 스핀체의 다른
  스핀 둘레 von Mises–Fisher(κ=20~50), 수락률에 제안밀도 비를 정확히 곱한다.
- 부격자 병렬 갱신은 아직 쓰지 않았다(순차 스윕). 성능이 병목이 되면 M3에서 도입한다.

## T = 0 상도 (단일 스핀체 최소화 vs 해석)
- T–C: K=0.5, zG=0.5에서 zH₄=0.6 경계, ±0.02에서 T/C 갈림.
- T–F: zH₄=0에서 zG=1.714, ±0.02에서 T/F 갈림.
- C–F: zH₄=1.5에서 zG=1.0, ±0.02에서 C/F 갈림.
- 절단선 C(K=0, zH₄=0): T(0.6, 0.78) → U(0.85–1.30) → F(1.36, 1.6). 경계 0.81, 1.33과 일치.
- 전역 최소 에너지는 해석식과 1e-9 이내. 모든 해석값과 어긋난 결과는 없다.

## 예상과 달랐던 점 / 주의
- 없음(해석값과의 불일치 없음). 단, D 상(꺾인 이량체)은 이번 점들에서 나타나지 않았다. 절단선 D는 C/F 경계이고
  D 상 영역은 아직 직접 찾지 않았다 → M3 전에 (zG, zH₄, K) 평면 훑기로 D 영역 위치를 확인할 것.
- 분할 분류는 문턱 0.95(스핀체 분류)·0.999(T=0 해 분류)를 쓴다. U/D 경계 근처에서 연속 분열이 있으면
  문턱 의존성이 생기므로 M3에서 문턱 민감도를 점검한다.
