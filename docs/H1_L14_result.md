## 고정 규칙의 적용
- 보정 규칙의 이중봉우리(세 조건 모두): **성립하지 않음.** L = 14의 보정 ΔBIC = −10.4(> 10 아님), 골 비율 1.00(< 0.9 아님), |2/3 − V_min|이 L = 8, 10, 12, 14에서 6.2 → 4.5 → 3.6 → 2.4 × 10⁻⁴로 줄어듦(멀어지지 않음).
- 짝별 지수 **a(12→14) = 0.14** (점추정; c_peak 오차를 전파한 1σ 약 ± 0.24). 0.9 이상이 아니다.
- 연속과 일관 조건: a(12→14) ≤ 0.7 ✓. |2/3 − V_min|이 L = 14에서 L = 12 값보다 작음(2.38 대 3.60 × 10⁻⁴) ✓.
- **판정: 연속과 일관** (V_min을 사다리 전체와 0.9–1.1 T_peak 구간 어느 쪽으로 읽어도 같음; `h1_verdict_l14`).

## 해석 (규칙 밖, 정성적)
- 앞선 "짝별 지수가 0.49 → 0.67로 커진다"는 L = 14에서 0.14로 내려갔다. 짝별 지수가 0.49, 0.67, 0.14로 단조롭지 않다. L = 10의 왕복이 6회뿐이고 L = 12의 c_peak 오차가 3.5라서, 앞의 증가 추세는 통계 요동일 가능성이 커 보인다. 전체 L = 8–14의 최소제곱 지수는 a = 0.48(오차 구간 [0.42, 0.53]; 오차 전파는 점마다 독립이라고 가정했고 지수가 L에 따라 변하는 것은 반영하지 않는다).
- c_peak가 26.5 → 36.8 → 52.9 → 56.4로 올라가는 것 자체는 사실이고, a(12→14)의 오차(± 0.24)가 커서 이 한 쌍으로 0.7 이하를 확정하지는 못한다(0.7까지 약 2.3σ). 규칙은 점추정을 쓰므로 판정은 위와 같지만 이 불확실성을 적는다.
- 3D zG = 0.5는 T = 0.147이다. 상관길이가 L보다 긴 약한 1차 전이를 완전히 배제하는 판정이 아니고, 고정한 규칙의 문턱으로 "1차 증거 없음"이라는 뜻이다.
