## H5 (U 상, 절단선 C: K = 0, zH₄ = 0, U 점 zG = 1.0, 1.2)
- **{211} 클러스터 모양 비율 > 0.5이고 m₁ ∈ [0.2, 0.3]인 온도 구간이 있을 것.**
- 구현(내가 정한 세부): 가열 사다리와 그 저온 사슬의 온도를 정렬해, 두 조건을 모두 만족하는 **연속한 3개 이상의 온도**를 '구간'으로 본다. {211}은 진단 `split`의 둘째 분류(1111, 211, 22, 31, 4 중). **U 점 두 개(zG = 1.0, 1.2) 모두 구간이 있으면 '지지'**, 아니면 '지지 안 됨'(점별로 보고).

## 재진입 (절단선 D: K = 0.5, zH₄ = 1.5, zG = 1.1, T = 0에서 F)
- **F → C가 가열과 냉각 양쪽에서 모두 보일 것.**
- 한 사다리에서 '보임': 어떤 T_low에서 m₁ ≥ 0.8(F), 더 높은 T_high에서 m₁ < 0.2이고 m₂ ≥ 0.7(C)이며, T_re는 그 사이에서 m₁ = 0.5를 처음 지나는 위쪽 선형 보간 온도(내가 정한 세부).
- **정량 예측**: H6 맞춤 zG\*(T) = 1 + 0.392 T + 0.15 T² = 1.1에서 **T_re ≈ 0.23, 허용 범위 0.21–0.26**. 가열과 냉각의 T_re **둘 다** 범위 안이면 '지지'(둘 다 보이지만 범위 밖이면 그렇게, 한쪽만 보이면 그렇게 기록).
- 주의(규칙 밖, 이전 결과): 무작위 시작 PT는 F, U, D 상에서 갇히는 것이 알려져 있다(M3). 냉각 쪽이 F에 닿지 못하면 '한쪽만 보임'으로 기록하고 이를 물리가 아니라 평형 문제로 구분해 쓴다.

## 2단계 3순위 결과 후 결정 (Oct 16, 계산 전에 고정)
### 1. 재진입 평형 T_re의 판 공존 보완 측정
- zG = 1.1(K = 0.5, zH₄ = 1.5), **T = 0.20–0.27(0.005 간격 15개), 시드 3개, 판 L = 24, 대각선 계면, 12000스윕**(H6와 같은 설정·같은 판 측정 절차, 영점 추정은 `crossing_with_systematics`: 영점 양쪽 따로 국소 맞춤 + 시드 재표집 + 창 선택 체계 오차).
- **판정 기준**: 판 공존의 v(T) 영점(F 비율이 자라는지 줄어드는지의 부호 변화) T_re가 **0.21–0.26 안이면 "평형 재진입 온도 예측 확인(보완 측정)"**으로 기록한다. 밖이면 그 값과 함께 "예측 미확인"으로 기록한다.
- **재진입 판정("한쪽 사다리에서만 보임")은 바꾸지 않는다.** 이 측정은 H6 맞춤(T = 0.10–0.20 자료)을 T = 0.234까지 외삽한 예측을 시험하는 의미가 있다.
- **규칙 설계의 문제(보고서에 기록)**: 사전 고정한 재진입 규칙은 양쪽 사다리(가열과 냉각)에서 F → C가 모두 보일 것을 요구했지만, C–F 경계가 1차라서 준안정이 크다는 점(가열은 과열, 냉각은 과냉각)을 고려하지 않았다. 규칙 자체가 평형 전이를 측정하지 못하게 설계된 것이다.
- H6 상한 1.12 보조 재스캔(T = 0.175, 0.20) 결과도 함께 보고한다(판정은 불변).

### 2. F → M2 → C 중간 상: 해석 계산을 먼저 (시뮬레이션 추가 조사는 하지 않는다)
- H6의 조화 자유에너지 코드(`polyspin/harmonic.py`의 `selection`)로 균일 공선 M2({31}, n_down = 1)의 조화 자유에너지를 계산하고, 조화 + 라벨 엔트로피로 C(k = 2), M2(k = 1), F(k = 0)의 자유에너지를 비교한다. x = zG − J, 에너지 E_k − E_F = x (n² − M²)/2(M = n − 2k), ΔF_k/T = (E_k − E_F)/T + δ_k, δ_k = ½(logdet_k − logdet_F) − ln C(n, k).
- **M2 쐐기의 정의**: ΔF_M2 < min(0, ΔF_C)인 (T, x)가 있으면 평형 M2 쐐기가 **예측된다**. 쐐기의 폭 T(δ_M2 − δ_C)/2 < x < −T δ_M2/6. (라벨 엔트로피만이면 0.203 T < x < 0.231 T, zG = 1.1에서 T ≈ 0.43–0.49.)
- **쐐기가 예측되면** 그때 판 공존(C|M2, M2|F 계면)으로 확인한다. **예측되지 않으면** 관찰된 M2(가열 T = 0.32–0.37)는 "**과열된 F가 C로 가는 준안정 경로**"로 기록한다.

### 3. C·D의 L = 24 (13 h): 하지 않는다
D는 PT 사다리가 병목으로 끊겨 얻을 것이 없고, C의 2D L = 24는 판정에 거의 기여하지 않는다. 대신 아래 3D U 점을 돌린다.

### 4. 절단선 C의 U 점(zG = 1.0, 1.2) 3D L = 8, 10
- 정렬 시작, 사다리(0.4–1.2 T_peak) + 저온 사슬, 약 1–2 h. **판정 규칙은 기존 H5 규칙 그대로**(`cd_rules.h5_intervals`): 연속 3개 이상의 온도에서 {211} 비율 > 0.5이고 m₁ ∈ [0.2, 0.3].
- **3D H5 판정**: 두 점(zG = 1.0, 1.2)과 두 크기(L = 8, 10) **모두** 구간이 있으면 "H5 지지(3D)". 3D에서는 U 상의 질서가 진짜 장거리 질서일 수 있으므로 H5를 **상에 관한 진술**로 만들 수 있다(2D L = 16의 결과는 크기 하나의 교차 영역에서의 진술이었다). 규칙을 만족하지 않는 점은 점·크기별로 보고한다.

### 5. B 3D 판 L = 16
H6 재스캔, 3D U, 위 결정과 별개로 병행한다. B 3D zH₄ = 1.0, 정렬 | 무질서 판 공존, L = 16, T = 0.350–0.366(0.002 간격 9개) × 시드 3개, 12000스윕(L = 12와 같은 설정, 같은 영점 추정), L = 12(T_c = 0.3573 ± 0.0005)와 비교한다.

## M2 쐐기의 판 공존 확인 (해석 계산이 쐐기를 예측했으므로, Oct 16, 계산 전에 고정; `docs/M2_wedge_analytic.md`)
- **예측(2D, zG = 1.1, 조화 + 라벨, T → 0 근사)**: F → M2가 **T₁ ≈ 0.243**, M2 → C가 **T₂ ≈ 0.265**(쐐기 폭 약 0.022).
- **측정**: zG = 1.1에서 (a) **M2|F 판**(왼쪽 M2 = 균일 공선 k = 1, 오른쪽 F)의 F 비율 속도 v(T), T = 0.20–0.28(0.005 간격 17개) → 영점이 T₁(F가 이기는 온도의 상한); (b) **C|M2 판**(왼쪽 C = k = 2, 오른쪽 M2)의 M2 비율 속도 v(T), T = 0.22–0.30(0.005 간격 17개) → 영점이 T₂(M2가 이기는 온도의 상한). 시드 3개, 판 L = 24, 대각선 계면, 12000스윕, 같은 판 측정 절차, 영점 추정은 `crossing_with_systematics`.
- **판정(내가 정한 세부)**: **"쐐기 확인"** iff T₁(측정) < T₂(측정)이고 그 차이가 두 영점 오차 합성값의 2배보다 크다. **"위치 일치"** iff |T₁ − 0.243| ≤ 0.03 그리고 |T₂ − 0.265| ≤ 0.03(허용 폭은 이전 H6 결합 맞춤의 b 항이 T_re를 0.26에서 0.234로 옮긴 정도, 비조화 보정의 크기). 쐐기가 확인되지 않으면(T₁ ≥ T₂ 또는 차이가 2σ 이하) **"M2는 평형 상이 아님; 관찰된 M2는 과열된 F가 C로 가는 준안정 경로"**로 기록한다.
- 같은 날 진행 중인 C|F 판 공존(zG = 1.1, T = 0.20–0.27)의 영점(재진입 보완 측정)은 규칙 그대로 기록하고, 이 쐐기 측정과 나란히 해석한다(쐐기가 실제면 C|F 판의 영점은 F|M2 경계 T₁ 쪽에 있을 것으로 예상, 해석 설명이며 사전 판정 기준은 아니다).

## 3D M2 쐐기 판 공존 (Oct 16, 계산 전에 고정)
- **원칙(앞으로 적용, 소급 없음)**: 영점 오차의 주 추정량은 **백분위 반폭**(16–84% 범위의 절반, `cc_fit.crossing_robust`의 sigma_total)이다. 표준편차도 함께 보고한다. 2D M2 쐐기 측정의 판정 기록(위치 일치 = 성립; 쐐기 확인 = 문자 그대로의 규칙으로는 불성립, 표준편차가 두 점 외삽 재표집의 꼬리로 부풀었음; 백분위 구간 T₁ 0.2317–0.2331, T₂ 0.2426–0.2571은 겹치지 않고 T = 0.235–0.245에서 모든 시드가 M2 유리 부호 → 쐐기는 존재한다고 판단)은 바꾸지 않는다.
- **3D 해석 예측(zG = 1.1, 조화 + 라벨, 같은 코드)**: 쐐기 x/T ∈ (0.3752, 0.4099) → **T₁ = 0.2440**(F → M2), **T₂ = 0.2665**(M2 → C).
- **측정**: 3D L = 12, 대각선 계면, 시드 3개, 12000스윕, M2|F 판(T = 0.200–0.280, 0.005 간격)과 C|M2 판(T = 0.220–0.300, 0.005 간격), 영점은 `crossing_robust`.
- **판정**: "위치 일치" iff |T₁ − 0.2440| ≤ 0.03 그리고 |T₂ − 0.2665| ≤ 0.03. "쐐기 확인" iff T₁ < T₂이고 T₂ − T₁ > 2·sqrt(σ₁² + σ₂²), σ는 백분위 반폭 기반 sigma_total. 표준편차 기반 값도 함께 기록한다. 실패 시 "M2는 평형 상이 아님(3D)".

## 3D M2 쐐기 T₁ 보완 측정 (Oct 17, 계산 전에 고정)
- **동기**: 원 측정에서 T₁의 σ_pct(0.0193)가 T = 0.235의 시드 한 개 때문에 부풀었다. 규칙은 바꾸지 않고, 같은 판정 규칙을 더 촘촘한 격자·더 많은 시드로 다시 적용한다. 원 측정의 판정(쐐기 불성립)은 기록으로 남기며 이 보완 측정이 대체하지 않는다.
- **측정**: 3D L = 12, zG = 1.1, M2|F 판(left k = 1, right k = 0, 측정 지표 2), **T = 0.226–0.246(0.002 간격 11개), 시드 6개(원 측정과 다른 시드 번호), 12000스윕**, 대각선 계면. 영점은 `crossing_robust`(주 오차 = σ_pct 기반 sigma_total, σ_std 병기).
- **판정**: T₁(보완) 으로 같은 규칙을 다시 적용한다. T₂는 원 측정 값(0.2527 ± 0.0016)을 쓴다(재측정하지 않음). "쐐기 확인" iff T₁ < T₂이고 T₂ − T₁ > 2·√(σ₁² + σ₂²); "위치 일치"는 원 규칙(±0.03). 보완 측정 결과가 원 측정과 다르더라도 둘 다 보고하며 보완 측정의 판정을 "보완 측정 판정"으로 따로 표기한다(원 판정을 덮어쓰지 않음).

## 비조화 보정 계산 (Oct 17 결정 (d), 계산 전에 고정; 코드 `tools/anharm.py`, `polyspin/analysis/anharm.py`)
**방법**: 분기 k = 0(F), 1(M2), 2(C)마다 정렬 시작 단일 온도 사슬(`slab.run_branch`, 교환 없음)로 클러스터당 에너지 e_k(T)를 잰다. 열역학 관계 e = e₀ + aT + cT² ⇒ f/T = βe₀ + a ln β − cT + const, 즉 **자유에너지의 T² 보정 = −c_k T²**. 가지 사이의 차이는 보정된 ΔF_k/T = (E_k − E_F)/T + δ_k − (c_k − c_F)·T (δ_k는 `selection`의 조화 + 라벨 값, 클러스터당).
- **격자와 점**: 2D L = 16, 3D L = 8; zG = 1.0, 1.1(K = 0.5, zH₄ = 1.5); 분기 3개; **T = 0.08–0.24, 0.02 간격 9개**; 평형 5000, 측정 20000스윕; 사슬마다 시드가 다르다.
- **맞춤(계산 전 고정)**: e_k(T) − e₀ = aT + cT² (e₀는 T = 0 정확값 = 정렬 상태의 에너지, a와 c 자유, 가중 최소제곱, 사슬의 블록 오차 가중). 차수 2로 고정한다. 민감도로 3차 항 추가(c의 변화)와 범위 0.08–0.20 축소를 보고한다. 점검: 맞춘 a가 조화 예측(n_dof/2, 유한 N 보정 포함)의 2% 안이어야 하며, 아니면 그 분기·격자를 판정에서 제외하고 이유를 쓴다. 사슬이 분기를 떠나면(자기 분기 비율 최소 < 0.9) 그 T를 맞춤에서 뺀다.
- **예측 불확도**: c의 맞춤 오차와 3차 항 민감도의 합성(σ_c)을 예측 오차로 전파한다.
- **보정된 예측**:
  - F|M2 경계 기울기와 곡률: zG* = J + a₁T + b₁T², a₁ = −δ_M2/6, b₁ = Δc_M2/6 (Δc_M2 = c_M2 − c_F); 이론에서 H6 맞춤의 b와 비교(측정 b = 0.15 ± 0.05).
  - 쐐기 위치(x = zG − J = 0.1): T₁은 6x/T + δ_M2 − Δc_M2 T = 0, T₂는 2x/T + (δ_C − δ_M2) − (Δc_C − Δc_M2)T = 0의 근(zG = 1.1, 2D와 3D 각각). 폭 T₂ − T₁.
- **판정 기준**: 보정된 예측이 측정한 b(0.15 ± 0.05), 쐐기 위치 T₁, T₂(2D, 3D 각각)를 **√(σ_측정² + σ_예측²)의 2배 안에서** 재현하면 '비조화 보정으로 설명됨'. 일부만 재현하면 재현된 항목과 안 된 항목을 나눠 보고한다. 측정값은 쐐기 판 공존의 영점을 `crossing_seedmean`(σ_total)으로 다시 계산한 값(2D는 기존 판 공존 자료, 3D는 T₁ 보완과 T₂ 재측정 자료)이며, 기존에 보고한 값도 병기한다. "σ_측정과 σ_예측을 합성한다"는 문구는 결정문('측정 오차의 2배 안')을 예측 불확도까지 포함해 읽은 나의 세부이다; 이의가 있으면 알려 달라.

## 비조화 보정: 열역학 적분 판 (Oct 17 최종 검토 답변 3, 계산 전에 고정; `tools/anharm.py integrate`)
**기록(결정)**: 이전 비조화 보정(다항식 맞춤)은 구현 규칙('σ_예측' 합성)에서는 다섯 항목 모두 '설명됨', 의뢰서 문구('측정 오차만')에서는 5개 중 3개 재현(b, T₁ 2D, T₂ 3D; 재현 안 됨 T₂ 2D, T₁ 3D)이다. 두 판정을 모두 장부에 남긴다. 기준이 어긋난 이유의 일부는 의뢰서가 σ_예측을 정의하지 않은 데 있다.
**방법**: 다항식 대신 분기 에너지를 적분한다.
δe(T) = e(T) − e₀ − a_h T,  δf(T) = −T ∫₀ᵀ δe(T′)/T′² dT′   (e = e₀ + a_h T + c T² 이면 δf = −c T²).
- a_h = n_dof/2 − (영 모드 수)/(2N) = **4 − 1/N**(조화 코드의 영 모드 수는 모든 분기에서 2, 즉 n_dof/2 = 4, 영 모드 2개).
- **자료**: 기존 분기 사슬(2D L = 16, 3D L = 8, zG = 1.0, 1.1, T = 0.08–0.24, 0.02 간격)에 **T = 0.02, 0.04, 0.06, 0.26**을 추가한다(분기 3 × zG 2, 평형 5000, 측정 20000스윕, 새 시드). 격자는 0.02 간격 균일(0.02–0.26, 13점).
- **적분**: T < 0.02 구간은 δe = c₀T²로 메워 ∫₀^{0.02} δe/T′² dT′ = c₀ · 0.02, c₀ = δe(0.02)/0.02²; 0.02 이상은 사다리꼴 공식(균일 격자). δf의 임의 T 값은 격자점의 δf를 3차 스플라인으로 보간한다. 민감도: 심프슨 공식(짝수 구간만)과 c₀를 δe(0.04)/0.04²로 바꾼 값을 보고한다.
- **점검**: δe(T)/T → 0이어야 한다(저온 점에서 |δe|/T² ≤ 3). 아니면 그 분기·격자를 보고하고 판정에서 뺀다.
- **분기 유지 점검**: 각 점의 자기 분기 분할 비율(own) ≥ 0.9인 온도만 쓴다. 떠난 온도 이상으로는 그 분기의 δf를 만들지 않으며 그 온도를 넘는 예측 항목은 판정에서 뺀다(zG = 1.0 2D F 분기의 T ≥ 0.20 등).
- **보정된 자유에너지**: ΔF_k/T = (E_k − E_F)/T + δ_k + (δf_k − δf_F)/T (δ_k는 `selection`의 조화 + 라벨 값).
- **예측 항목(다섯 개)**: (1) b: F\|M2 경계 x*(T) = −Tδ_M2/6 − (δf_M2 − δf_F)(T)/6을 **zG = 1.1 분기 자료의 δf**로 구해(주), T = 0.10, 0.12, 0.14, 0.16, 0.18(F와 M2 분기가 유지되는 온도, H6 측정 범위 0.10–0.20의 부분집합) 위에서 x* = aT + bT² 맞춤의 b, 측정 b = 0.15 ± 0.05(2D). zG = 1.0 분기 자료로 구한 값은 zG 의존성의 정보용으로 병기. (2–5) T₁, T₂ (2D, 3D): zG = 1.1(x = 0.1)에서 6x/T + δ_M2 + (δf_M2 − δf_F)(T)/T = 0, 2x/T + (δ_C − δ_M2) + (δf_C − δf_M2)(T)/T = 0의 근.
- **판정 기준**: **σ = √(σ_측정² + σ_적분²)**, σ_적분은 분기 에너지의 통계 오차(사슬의 블록 오차)를 적분과 스플라인에 전파한 값만(몬테카를로 2000회, 각 T의 δe를 정규 분포로 재표집). 다항식 민감도 항은 없다. 2σ 안이면 재현. **다섯 항목 모두 재현이면 "비조화 보정으로 정량적으로 설명됨"**, 일부면 재현 항목과 안 된 항목을 나눠 보고한다. 측정값은 이전과 같다(2D T₁ 0.2338 ± 0.0005, T₂ 0.2560 ± 0.0019: 기존 판 공존 자료의 시드 평균 추정기 값; 3D T₁ 0.2356 ± 0.0008, T₂ 0.2541 ± 0.0064; b 0.15 ± 0.05).
- **한계(계산 전 기록)**: 사슬 크기(2D L = 16, 3D L = 8)가 판 크기(2D L = 24, 3D L = 12)와 다르다. b의 측정은 2D뿐이다.
