## H5 (U 상, 절단선 C: K = 0, zH₄ = 0, U 점 zG = 1.0, 1.2)
- **{211} 클러스터 모양 비율 > 0.5이고 m₁ ∈ [0.2, 0.3]인 온도 구간이 있을 것.**
- 구현(내가 정한 세부): 가열 사다리와 그 저온 사슬의 온도를 정렬해, 두 조건을 모두 만족하는 **연속한 3개 이상의 온도**를 '구간'으로 본다. {211}은 진단 `split`의 둘째 분류(1111, 211, 22, 31, 4 중). **U 점 두 개(zG = 1.0, 1.2) 모두 구간이 있으면 '지지'**, 아니면 '지지 안 됨'(점별로 보고).

## 재진입 (절단선 D: K = 0.5, zH₄ = 1.5, zG = 1.1, T = 0에서 F)
- **F → C가 가열과 냉각 양쪽에서 모두 보일 것.**
- 한 사다리에서 '보임': 어떤 T_low에서 m₁ ≥ 0.8(F), 더 높은 T_high에서 m₁ < 0.2이고 m₂ ≥ 0.7(C)이며, T_re는 그 사이에서 m₁ = 0.5를 처음 지나는 위쪽 선형 보간 온도(내가 정한 세부).
- **정량 예측**: H6 맞춤 zG\*(T) = 1 + 0.392 T + 0.15 T² = 1.1에서 **T_re ≈ 0.23, 허용 범위 0.21–0.26**. 가열과 냉각의 T_re **둘 다** 범위 안이면 '지지'(둘 다 보이지만 범위 밖이면 그렇게, 한쪽만 보이면 그렇게 기록).
- 주의(규칙 밖, 이전 결과): 무작위 시작 PT는 F, U, D 상에서 갇히는 것이 알려져 있다(M3). 냉각 쪽이 F에 닿지 못하면 '한쪽만 보임'으로 기록하고 이를 물리가 아니라 평형 문제로 구분해 쓴다.
