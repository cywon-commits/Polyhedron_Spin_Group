# H1 판정 규칙: 3D A zG = 0.5, L = 14 추가 실행 (실행 전에 고정, Oct 13)

사용자 결정으로 L = 14 실행 전에 다음 규칙을 고정한다. 구현은 `polyspin/analysis/finite_size.py::h1_verdict_l14`(단위 테스트 포함). 결과를 본 뒤 바꾸지 않는다.

- **1차**: 보정 규칙의 이중봉우리 판정(보정 ΔBIC > 10, 골 비율 < 0.9, |2/3 − V_min|이 L과 함께 2/3에서 멀어짐 — 세 조건 모두)이 성립하거나, 짝별 지수 a(12→14) ≥ 0.9.
- **연속과 일관**: a(12→14) ≤ 0.7이고 |2/3 − V_min|이 L = 14에서도 계속 줄어듦(L = 12 값보다 작음).
- **그 외**: 판정 불가(약한 1차 후보).

근거(사용자): 3D 표준 연속 전이의 a = α/(dν)는 약 0.06 이하이므로 a = 0.56이 L과 함께 커지는 모습은 상관길이가 L보다 긴 약한 1차 전이의 전형일 수 있다.
a(12→14)는 L = 12, 14의 c_peak 점추정으로 계산하고(규칙은 점추정에 적용), 잭나이프 오차를 함께 보고한다. c_peak의 온도는 각 L의 비열 최댓값 온도, V_min은 사다리 전체와 0.9–1.1 T_peak 구간 양쪽을 보고하며 규칙의 조건 (3)은 두 값이 모두 줄어들 때 "줄어듦"으로 본다. (이 마지막 세부 해석은 규칙 고정 시점에 내가 추가한 것이다.)
