### 2. 절단선 E(K = −0.5, zH₄ = 0)는 의뢰서의 전제(질서 있는 C 네마틱)가 성립하지 않는다 — E′ 제안
- zH₄ = 0에서 C(↑↑↓↓)는 M = 0이라 홀수 채널이 사라지고 x⁴ 항도 없어, **스핀체 사이 에너지 결합이 정확히 0**이다. 그래서 C 영역(zG = 0.5)에서 m₂ ≈ 0.12로 질서가 없고, (e − E₀)/T = 3.0(스핀체당 영모드 2개: 공선 축의 방향)이다. T = 0에서 C로 분류되지만 네마틱 상이 아니다.
- D 상은 M ≠ 0으로 홀수 채널을 통해 결합하지만 결합 세기가 M²에 비례해 작고, 방향 무질서 상태의 엔트로피가 커서 **방향 질서가 매우 낮은 온도에서 무너진다**: 정렬 시작 기준 T_c ≈ 0.025(zG = 0.8), ≈ 0.09(zG = 1.0). 무작위 시작은 T = 0.01에서도 질서를 못 찾는다(위 1번).
- 따라서 의뢰서의 H12(C 네마틱의 디렉터 n축 SO(2)를 M⊥가 깨는 연속 전이)는 E에서는 검증할 수 없다.
- **E′ 제안: K = −0.25, zH₄ = 0.25** (T = 0 상: zG = 0.6 C, 0.9 D, 1.0 D, 1.1 F). 정렬 시작 2D L = 8 결과(예비): zG = 0.9에서 m₁이 T = 0.01의 0.22에서 0.19, 0.09, 0.05로 **연속적으로 0이 되고**(τ가 T ≈ 0.1에서 최대) m₂ ≈ 0.9인 C 네마틱으로 넘어가며, C는 T ≈ 0.3에서 녹는다(비열 피크 23–26). zG = 1.0도 같다(m₁ 0.32 → 0.06 at T ≈ 0.22). 즉 H12가 겨냥한 C–D 연속 전이와 그 위의 네마틱 전이가 둘 다 접근 가능한 온도에 있다. 무작위 시작은 C(0.6), D(0.9)에서 평형에 도달한다.

### 3. 계산 비용: 의뢰서 규모로는 이 기계에서 불가능하다
- 교환율 0.3을 위한 복제본 수는 √N에 비례해 늘어난다 (2D L = 16: 약 90–105개, L = 48: 약 310개. 3D L = 8: 121개, L = 16: 약 340개). 한 번 왕복하는 데 약 R² 스윕이 필요해 **통계 비용은 N²에 가깝게** 늘어난다 (3D L = 8, R = 121, 9천 스윕에서 왕복 0회).
- 유휴 4코어 실측: 2D L = 16(R = 90) PT 스윕당 20.5 ms, 3D L = 8(R = 121) 63.5 ms. 이 값으로 절단선 18개 점 전체, 점당 10⁵ 스윕이면 2D L = 16/24/32/48에서 각각 12/40/95/319 시간, 3D L = 8/10/12/16에서 31/85/194/707 시간(표는 아래). 전체 합계는 수천 시간이다.

### 4. 결함 통계는 전이 근처에서 문턱 선택에 민감하다
- 2D L = 8 T 상(zG = 1.0)에서 단일 스핀체의 정사면체 맞춤 잔차의 중앙값이 T = 0.06에서 0.09, 0.17에서 0.17, 0.28에서 0.31로 커져서, 전이(T ≈ 0.22) 근처에서는 기본 문턱(잔차 0.35, 겹침 0.9)으로 플라켓의 약 절반이 '정의 불가'가 되고 블록 통계(k = 2, 3)는 T ≳ 0.17에서 모두 '정량값 아님'(비자명 블록 비율 > 0.1)이다. T ≤ 0.13에서는 정의 불가·모호가 0.3% 미만이고 결함은 검출되지 않는다(밀도 < 10⁻⁴).
- 대응: 모든 실행이 문턱 조합(잔차 0.35–0.7, 겹침 0.5–0.9, 여유 0.15–0.25) 6종에서의 류별 신뢰 개수와 모호/정의 불가 수, 맞춤 잔차 히스토그램을 온도별로 저장한다. 전이 근처의 류 밀도(H1, H2)는 이 스캔의 안정성을 확인한 뒤에만 보고한다. 결함이 전이 이전에 증식하는지 클러스터 변형 때문에 틀 자체가 무너지는지의 구별이 H2의 핵심이므로, M4 전에 문턱을 정해야 한다(아래 질문 3).

### 5. 긍정적 선행 결과 (예비, 2D L = 8 / 판 L = 16)
- **H6 재진입 징후**: D 절단선 zG = 1.1(T = 0에서 F)의 정렬 시작은 T ≈ 0.28까지 F(m₁ ≈ 1)를 유지하다 T ≈ 0.3–0.37에서 m₁이 1 → 0.03으로 떨어지고 m₂ ≈ 0.9가 남는 **C로 간 뒤** T ≈ 0.6–0.8에서 녹는다. 조화 + 라벨 예측(T\* ≈ 0.26)과 대체로 맞다. zG = 1.0(축퇴점)에서는 C가 전 구간에서 선택된다. 이 전이는 교환율이 0인 1차라 정밀한 T_c는 판 공존법으로 정해야 한다.
- **판 공존법 작동**: L = 16 판, T = 0.1, K = 0.5, zH₄ = 1.5: zG = 0.96에서 F가 사라져 전부 C, 1.00–1.02에서 F 비율 감소, 1.10에서 전부 F. 계면이 멈추는 zG는 1.02–1.10 사이이고 하계 예측 zG\* = 1.038과 모순이 없다. 다만 zG = 1.04, 1.06에서는 계면이 6만 스윕 동안 완전히 고정(격자 핀 고정)되어, 정밀 판정에는 더 촘촘한 zG와 긴 실행이 필요하다.
- **H1 선행**: 3D L = 8 A 절단선 전 점(zG = 0.5, 1, 1.5, 2)에서 전이마다 인접 온도 사이 에너지 점프(0.17, 0.44, 0.46, 2.5/클러스터)가 있고 비열 피크가 25.7, 18.5, 20.8, 18.5(64개 사다리)이다. 정식 판정(에너지 히스토그램 이중 봉우리, 잠열의 크기 의존성)은 M4에서 한다.

## 후속 4 반영 (코드)
- **결함 통계 용도 분리**: 류 밀도는 k = 2 블록(기본), k = 3은 수렴 확인; 위치/쌍 거리/핵 상관은 단일 플라켓(신뢰와 모호를 따로 기록). `block_census`가 (2k − 1)² 중복 계수 보정, 비자명 블록 비율, 비율 > 0.1이면 `quantitative = False`를 낸다. 모호 문턱은 플라켓 0.15 기본, 블록 0.25, 0.15–0.25 스캔은 진단.
- **블록 = 플라켓 곱 (비가환 Stokes)**: `block_from_plaquettes`가 블록 경계 원소를 내부 플라켓 홀로노미의 평행이동 곱으로 재구성하고, 임의 q, 임의 m × n 직사각형, 2D/3D 모든 평면에서 직접 계산과 일치함을 테스트로 고정했다(곱 순서를 바꾸는 변이에서 실패). 2π 와류가 코어 플라켓에서 `6−`으로 읽혀도 같은 블록 안에 보상 결함이 생기고 블록 순 류는 정확함도 테스트.
- **H6 판정 도구**: 기울기 판별(`zG*(T) = J + aT + bT²`, 예측 a = 0.382 / 라벨만 0.224 / 조화만 0.158)은 M5 분석에서 적합; 판 공존법은 `polyspin/slab.py`, 재진입은 절단선 D의 정렬 시작 가열 스캔으로 본다.
- 해석상 주의 반영: C–D 근방의 √ 시작은 T = 0 분기의 성질이며 H12의 유한 온도 보편성 증거로 쓰지 않는다. U와 D는 m₁로 구별되지 않으므로 형태 진단(분할 히스토그램)을 쓴다.

## 구현 (M3)
- `pt.py`: 복제본 교환, 복제본별 xoshiro(스레드 수와 무관한 비트 재현성), 온도별 스텝 조정(평형 단계만), 체크포인트/이어하기, 왕복·흐름 진단, 히스테리시스 스캔.
- `run.py`: YAML 한 개 = 실행 한 개 = HDF5 한 개(시계열, 진단 합, 최종 배치, 시드, 매개변수, git 해시, 체크포인트). 히스테리시스 모드. 상(T, U, D / C / F)에 따라 결함 검출기 자동 선택.
- `measure.py`, `observables.py`: m₁…m₄, 분할 히스토그램, A_l 분포, |M_a| 히스토그램, 공선성, G_l(r), 류별 결함 통계(플라켓, 블록, 문턱 스캔), Z₂ 반와류, 스커미온 전하.
- `analysis/`: τ_int(Sokal 자동 창), 블록/잭나이프 오차, Binder, 감수율, 요약 로더, **사다리 설계**: 비열과 e(T)로 교환율을 예측해 사다리를 짠다. 예측은 실측 교환율과 평균 0.002 차이로 일치했고(2D L = 8, 40개 온도) 작은 계의 측정값으로 큰 계의 사다리를 설계할 수 있다.
- 구현 선택(Numba): 복제본 수준 `prange` 병렬 + 단순한 국소 ΔE 커널이라 C++ 이득이 작다. 겹침/분열 이동은 PT와 함께 쓴다(상세 균형 보장, 생략 없음). 부격자 병렬 갱신은 쓰지 않았다(복제본 병렬로 충분).

## 결정이 필요한 것
1. **E → E′ 교체?** E(K = −0.5, zH₄ = 0)는 위 2번 이유로 H12를 검증할 수 없다. E′(K = −0.25, zH₄ = 0.25; zG = 0.6, 0.9, 1.0, 1.1)로 대체하고 E는 예비 결과만 보고하는 안을 권한다.
2. **본 계산 규모 축소**: 의뢰서의 10⁵ + 10⁵ 스윕과 전 크기는 비현실적이다. 제안: (a) 점당 스윕을 τ 기반(평형 + 측정 각 ≥ 200τ, 연속 전이 점은 약 2–5 × 10⁴, 1차 점은 별도)으로 줄이고, (b) 3D는 L = 8, 10, 12(16은 보류), 2D는 L = 16, 24, 32(48은 보류)로 시작, (c) 저온 조화 영역(T < 0.03)은 교환 없이 정렬 시작 단일 온도 실행으로 대체해 복제본 약 15% 절감, (d) 1차 점은 정렬 시작 PT + 판 공존법/히스토그램 재가중. 이 안으로 A, B(7점) 약 100–150 h로 줄일 수 있다. 어느 범위까지 계산할까요?
3. **결함 문턱**: 전이 근처에서 틀 맞춤 잔차가 커져 기본 문턱으로는 정의 불가가 많다(위 4번). H2에서 결함 밀도가 급변하는 온도를 보려면 잔차 문턱을 0.5–0.7로 키우는 것이 필요할 수 있다. 문턱 스캔 결과가 안정한 범위를 M4 첫 실행에서 정한 뒤 고정해도 되는가?
