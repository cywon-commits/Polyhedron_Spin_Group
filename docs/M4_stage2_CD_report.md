# M4 2단계 3순위 보고: 절단선 C, D (2D L = 16)

14개 실행(C 4점, D 3점의 가열·냉각 사다리)을 끝냈다. 판정 규칙은 계산 전에 `docs/CD_rules.md`에 고정했다(코드 `polyspin/analysis/cd_rules.py`, 테스트 포함). 표는 `tools/cd_analysis.py`가 만들며 `docs/CD_L16_tables.md`에 있다. 재개된 실행은 없다(`resumed_at_blocks` 모두 빈 목록). **T = 0 해석값과 모순되는 결과는 없다.**

## 규칙으로 판정한 것

| U 점 | {211} > 0.5이고 m₁ ∈ [0.2, 0.3]인 온도 구간(연속 3개 이상) | 점 수 | 최저 온도의 {211} 비율 |
| --- | --- | --- | --- |

두 U 점 모두 구간이 있다. m₁은 저온에서 0.24–0.25로 유지되다 구간 끝(각각 약 0.14, 0.20)에서 급격히 줄어든다. {211} 비율은 저온 0.96–0.98에서 구간 끝에서 0.5 근처로 내려간다.

### 재진입 F → C (절단선 D, zG = 1.1): **한쪽 사다리에서만 보임** (규칙의 결과)
| 사다리 | 저온에서 F (m₁ ≥ 0.8) | F → C 보임 | T_re | 허용 범위 0.21–0.26 안 |
| --- | --- | --- | --- | --- |
| 가열(정렬 시작) | 1.00 | 예 | **0.316** | 아니오 |
| 냉각(무작위 시작, 0.12–0.95) | 0.03(F에 못 닿음) | 아니오 | – | – |
- 규칙(양쪽 모두에서 보이고 T_re가 범위 안)은 **충족되지 않는다.** 가열에서는 F가 T = 0.30까지 m₁ ≈ 0.99로 유지되다 0.316에서 떨어진다. 냉각에서는 고온에서 C(m₂ ≈ 0.97)가 되고 **T = 0.12까지 내려가도 m₁ ≈ 0.00**으로 C에 머문다(F로 가지 않음).
- **해석(규칙 밖)**: 이 모형의 C–F 경계는 1차라서 준안정이 크다. 가열 T_re(0.316)는 평형값 위로 +0.08 과열, 냉각은 평형값 아래(< 0.12)까지 과냉각이다. **H6 결합 맞춤의 평형 예측 T_re = 0.234 ± 0.008**(zG\*(T) = 1 + 0.392 T + 0.15 T² = 1.1을 a, b의 오차로 전파)은 두 준안정 한계 (< 0.12, 0.316) 사이에 정확히 놓인다. 즉 규칙은 "양쪽에서 보임"을 요구했지만 냉각이 F에 닿지 못하는 것은 사전에 알려진 평형 문제(무작위 시작 PT는 F, U, D 상에서 갇힘, M3)이며, 이 결과가 H6 예측과 모순된다는 뜻은 아니다. 다만 사전 규칙의 정량 예측(T_re ∈ 0.21–0.26)은 **이 실험으로 직접 확인되지 않았다.** 평형 T_re의 직접 측정은 판 공존(zG = 1.1에서 T를 스캔)이 맞는 방법이다(제안: 아래).
- **정성적 관찰(판정 밖)**: 가열에서 F가 곧바로 C로 가지 않는다. T ≈ 0.312에서 **{4}(F) → {31}(모멘트 2의 클러스터)로 바뀌어 T = 0.32–0.37에서 m₁ ≈ 0.49(= 2/4), {31} 비율 0.70–0.81**, 그다음 T ≈ 0.38에서 m₁ ≈ 0.01, {22} 0.37 + {211} 0.47인 C 쪽 상태가 된다. 즉 **F → M2 → C의 중간 상**이 보인다. 냉각 사다리에서는 이 구간에서 항상 m₁ ≈ 0.01이다. 규칙이 정한 T_re(m₁ = 0.5를 처음 지나는 위쪽 보간)는 F → M2 단계의 0.316이다.

## 나머지 점 (판정 규칙 없음, 관찰)
- C 절단선 비열 극대(가열 사다리): zG = 0.6 T 상 0.111, zG = 1.0 U 상 0.146–0.159(가열 0.146, 냉각 0.159), zG = 1.2 U 상 0.197, zG = 1.6 F 상 0.302. 시험 L = 8(0.113, 0.162, 0.194, 0.306)과 같은 값이다.
- D 절단선 zG = 0.9, 1.0, 1.1: C 상(또는 F → C 이후)의 네마틱 녹음 비열 극대 T = 0.618–0.623(세 점이 같다, 시험 L = 8의 0.635와 일치). 이는 G가 홀수 채널에만 들어가고 네마틱 녹음은 짝수 채널(K, zH₄)이 정한다는 E′의 결과(T₂가 zG와 무관)와 같다.
- PT 상태: 교환율 최소(왕복): C zG = 0.6 가열 0.18(36), 냉각 0.17(39); zG = 1.0 가열 0.16(0), 냉각 0.24(48); zG = 1.2 가열 0.13(10), 냉각 0.16(20); zG = 1.6 가열 **0.00(0)**, 냉각 0.27(22); D: 가열 0.04–0.05(0–2), 냉각 0.00–0.06(2–8). **D 절단선의 사다리는 병목 때문에 왕복이 거의 없다**(상 사이를 오가는 것이 아니라 각 상 안에서의 평형만 보장). 이 때문에 위 H5, 재진입 판정은 병목에 끊긴 사다리 위의 관찰이며, 온도 구간별 분류는 정렬 시작에서 얻은 값이다.

## 알릴 한계
1. 재진입의 정량 예측은 직접 확인되지 않았다(규칙의 결과: 한쪽만 보임, T_re(가열) = 0.316은 범위 밖). 평형 T_re는 판 공존으로 재야 한다.

3. H5의 구간은 L = 8 시험의 같은 구간(T ≲ 0.12, 0.18)과 비슷하다.
